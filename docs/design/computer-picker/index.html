Computer picker

How a person adds another Mac or Linux box to Oby and switches the whole window to it. Every screen is 1280 by 800, the Electron app’s own look on mock data. The words, and what obid provides for each state, are in README.md.

01No other computer yet

The computer button sits at the mini sidebar’s foot, above Settings: This Mac’s laptop, “This Mac” on hover. Its menu is the profile menu’s kind. With only this Mac, one line says what it is for.

02Adding one over SSH

“Add a computer…” opens one small sheet, as New project does. Over SSH is first: the person types the host as they would in a terminal. Oby runs their own ssh; it reads no SSH config and installs nothing.

03Adding over SSH: working

The same sheet, its three steps as they happen. The first two are obid pair-computer over the person’s SSH, then the tunnel; the third finds a faster way in (the local network, a tailnet), so SSH is only the fallback.

03bAdding over SSH: SSH says no

When ssh refuses, the sheet says what to do in obid’s own words (COMPUTERS-5). A host key is the person’s call: Oby never accepts one for them.

04Adding one with a code

Without SSH: the other computer shows a link and a code. Pasting the link shows that computer’s name and its certificate’s fingerprint, to check against its screen; the code then pairs. The link carries the pin, the code alone never.

05The other computer’s code

On the other computer (here a Mac named Studio, with Oby): Add a computer › With a code › Show this computer’s code. It says where it can be reached; each address is on until the person turns it off. A Linux box prints the same with obid invite-computer.

06Connected: the window works on Studio

The whole window is Studio’s: its profile, projects and conversations, run by its own Oby. The button shows its computer, the message box says where it goes, and the menu says how it’s reached. Hovering a row shows ⋯: Rename…, Remove….

07Reconnecting on a fallback route

Studio’s local address stopped answering, so Oby moves to the next route by itself. The window’s own connection line (Sangam’s, “Connecting to Oby’s engine…”) says so, after 2 s, and goes once it holds. Back on the local network later, nothing shows.

08Unreachable

No route answers. Home says so once, with every route tried and why (COMPUTERS-3); elsewhere the same words are the red-edged connection line. Studio’s last list stays, dimmed. Its tasks keep running there.

09Switching back to this Mac

This Mac picked in the menu (or “Back to This Mac”). For the moment it takes, the panel empties, Oby says where it’s going, and nothing on Studio stops.

10Removing a computer

From a row’s ⋯ in the menu. It revokes this Mac’s access over its own token and Studio forgets its key (COMPUTERS-16). Removing the computer in use switches back to This Mac first.
