# refactor(electron): the mock as a fake obid behind `window.app.obid`

<!-- Roadmap R06-12 · Sprint 6 · R06 Events that clients only apply · effort M · risk low -->

### Sangam's screen

uses an existing screen: apps/electron/src/renderer/src/Home.tsx and SettingsView.tsx under ?everything (no visual change)

### Outcome

`npm run web` and `?everything` keep working for Sangam, but the mock is a fake obid that plays scenarios through the same call and event interface, and production code imports nothing from it.

### Status and scope

Proposed (roadmap R06-12, milestone R06 Events that clients only apply).

**Why:** live.ts imports AGENTS, STEER, TELL and view types from mock.ts (live.ts:6, :15); 27 renderer files import './mock'; the live state is mapped into the mock's view types (map: 'The live data model is the mock's view model').

**In:**
- Move the view types and constants live.ts uses out of mock.ts into new: apps/electron/src/renderer/src/view.ts.
- A fake `window.app.obid` (call, confirm, publish, limitAnswer, pairInvite, live) that answers from scenario data and sends events through the same reducer.
- lean.ts's `?everything` and `?dev=` scenarios run on the fake obid.

**Out:**
- Changing any of Sangam's screens or their words.
- Generated wire types (R07).

### Actors and ownership: what obid owns

- Nothing.

### Actors and ownership: what the apps show and send

- Sangam's mock screens, unchanged.

### Steps

- Move the types and constants into view.ts; update imports file by file.
- Write fakeObid.ts with the preload's obid interface and the scenarios mock.ts holds.
- Install it in renderer/src/obid.ts when `window.app` is missing or `?everything` is on.
- Write LIVE-22 to 24; compare `npm run web` with `?everything` before and after by screenshots.
- Run `npm run typecheck`, `npm test` and `npm run build`.

### Acceptance scenarios

- LIVE-22 (proposed): Given the source of live.ts, when the test reads its imports, then none is './mock'.
- LIVE-23 (proposed): Given `npm run web` with `?everything`, when the app opens, then Home, the Tasks list and Settings show the mock's scenario data as today.
- LIVE-24 (proposed): Given a scenario event from the fake obid, when it is applied, then it goes through live-state.ts `apply` as a real event does.
