## What
Oby's own factory (`factory/bin/oby-feed`) starts every build on `--account` (default `deskree-team`). The Claude Code factory (`/factory run`) routes reviewers from `factory/config.json`'s `routing` and `surface_reviewers` (`factory/bin/route`), and each agent's model is its `.claude/agents/*.md` frontmatter. Both should follow the same roster: the project's `factory.json` (B00-06).

## Why
- **One roster, two factories.** The owner changes a step once, in Settings › Factory, and both follow.
- **Pause from the box** (B00-05) must stop oby-feed starting new tasks, as the owner does by hand when the factory drains.

## How
1. `oby-feed` reads `GET /v1/projects/{id}/factory/settings` at each pass and passes `agent`, `account`, `model` and `effort` in `POST /v1/jobs`. `--account` stays as a one-run override. While the project's factory is paused (B00-05), a pass starts nothing.
2. `factory/config.json` gains a `steps` block in the same shape. `bin/route` reads `steps.review.*` (`byRisk`, `when`) when present, and `routing` and `surface_reviewers` otherwise, so nothing changes until the block is added. Each agent is spawned with `steps.<step>.model` over its frontmatter.
3. `factory/config.json` is a protected path and a security path: this pull request waits for the owner's click (AGENTS.md, "Software factory").
