# feat(obid): keep rebuildable and secret folders out of Time Machine, and stamp the home

<!-- Roadmap R12-14 · Sprint 10 · R12 Developer workflows · effort S · risk low -->

### Sangam's screen

engine only

### Outcome

Backups stay small and hold no login copies, and an older obid never silently rewrites a newer home.

### Status and scope

Proposed (roadmap R12-14, milestone R12 Developer workflows).

**Why:** #1302: no exclusion code exists (grep for `excludeItem` and `addexclusion` in core/crates/obid/src finds nothing). obid writes `clones/`, `worktrees/`, `tmp/` and `logins/` under its home.

**In:**
- At start and whenever obid makes them, set the sticky backup-exclusion attribute on `clones/`, `worktrees/`, `tmp/` and `logins/` (the attribute `tmutil addexclusion` sets), macOS only.
- Write `home/format.json` with the obid version that last wrote the home.
- An older obid that finds a newer stamp starts read-only and says so in GET /v1/status, unless started with `--downgrade`.
- Say in docs/install.md what a backup keeps and what it does not.

**Out:**
- Encrypting the home.

### Actors and ownership: what obid owns

- The attribute, the stamp and the read-only mode.

### Actors and ownership: what the apps show and send

- Read-only shows through the status text clients already show; no new screen.

### Interfaces and dependencies

- GET /v1/status: `readOnly` with a reason (add-only).

### Steps

- Write one function that marks a folder and call it where each folder is made.
- Add the stamp read and write at start in lib.rs.
- Add `--downgrade` to main.rs's parser and its test.
- Make write routes answer 503 with the reason while read-only.
- Document the backup.

### Acceptance scenarios

- MOVE-12 (proposed): Given a home with and without the four folders, when obid starts or makes one, then each carries the exclusion attribute.
- MOVE-13 (proposed): Given `format.json` from a newer obid, when an older obid starts, then it is read-only and GET /v1/status says why.
- MOVE-14 (proposed): Given the same home and `--downgrade`, when it starts, then it runs normally and rewrites the stamp.

Contract: new: docs/contracts/moving.md (prefix MOVE)
