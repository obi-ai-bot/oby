# feat(obid): a registry change restarts warm sessions with the new list

<!-- Roadmap R11-10 · Sprint 10 · R11 Connections: MCP, sign-in and the vault · effort S · risk low -->

### Sangam's screen

engine only

### Outcome

After a server is added, removed or signed out, a warm conversation process and a resumable job session start their next turn with the new server list, so a removed server never stays in an agent's tool list.

### Status and scope

Proposed (roadmap R11-10, milestone R11 Connections: MCP, sign-in and the vault).

**Why:** The broker closes a removed server at the next call (R11-07), but a warm Claude Code conversation process (brain/harness.rs, --mcp-config at :538) keeps the tool names it listed, and the agent goes on trying them.

**In:**
- A registry generation number bumped on every change.
- brain/harness.rs: a warm process started on an older generation is ended between turns and the next turn starts a new one on the same session.
- Jobs: a resumed turn (follow-up, Try again) writes a fresh MCP config.

**Out:**
- Interrupting a turn that is running.

### Actors and ownership: what obid owns

- When a session's server list is stale and when to restart it.

### Actors and ownership: what the apps show and send

- Nothing changes for clients.

### Steps

- Add the generation counter to the registry.
- Keep the generation a warm process started on; compare before reusing it.
- Write a fresh MCP config at every job resume.
- Add CONNECT-16 to 18 with the fake harness agent.

### Acceptance scenarios

- CONNECT-16 (proposed): Given a warm conversation process that listed a row's tools, when the row is deleted between turns, then the next turn runs in a new process whose tools/list has no such tool, in the same conversation session.
- CONNECT-17 (proposed): Given a turn under way, when the registry changes, then the turn finishes undisturbed and only the next turn restarts.
- CONNECT-18 (proposed): Given an ended job resumed with a follow-up after a row was added, when its agent lists tools, then the new row's tools are there.
