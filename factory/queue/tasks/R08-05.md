# refactor(obid): usage reads, model lists and identity behind AgentDriver

<!-- Roadmap R08-05 · Sprint 5 · R08 One interface for every agent CLI · effort M · risk medium -->

### Sangam's screen

engine only

### Outcome

Reading an account's usage, listing its models and reading who it is are driver methods, so usage.rs, model_lists.rs and accounts.rs lose their per-tool branches.

### Status and scope

Proposed (roadmap R08-05, milestone R08 One interface for every agent CLI).

**Why:** jobs.rs ~2457-2480 branches to `agent::read_usage`, Codex's `account/rateLimits/read` and cursor_usage.rs; usage.rs has three parsers; model_lists.rs and accounts.rs `identity_from` (2139) match on the tool. Map: 'Every rule is written three times' (usage.rs: claude, codex, cursor parsers).

**In:**
- `AgentDriver::read_usage`, `list_models`, `identity` implemented by calling today's functions.
- jobs.rs `read_due_usages`, `refresh_models`, model_lists.rs and accounts.rs `identity_from` call the driver.

**Out:**
- Changes to how often usage is read: R08-09.
- Sign-in: R08-12.
- ChatGPT's own usage path (chatgpt.rs) beyond calling it from the Codex driver.

### Actors and ownership: what obid owns

- Which driver reads usage, models and identity.

### Actors and ownership: what the apps show and send

- Nothing changes for clients.
