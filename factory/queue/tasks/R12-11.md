# feat(obid): a conversation stages a workflow proposal; only the owner's yes saves it

<!-- Roadmap R12-11 · Sprint 10 · R12 Developer workflows · effort S · risk low -->

### Sangam's screen

uses an existing screen: the inbox item that shows 'Can I remember that?' today (file not confirmed; see unknown)

### Outcome

When the owner says in a conversation how a repository's PRs should merge, Oby asks 'Can I remember that?' at the end of the turn, instead of waiting for a merge card or a find.

### Status and scope

Proposed (roadmap R12-11, milestone R12 Developer workflows).

**Why:** A typed `workflow` memory (memory.rs `ask_workflow`, `remember_workflow`) is saved only from a merge card or `find`. A workflow the owner states in words is lost.

**In:**
- A tool `oby_remember` in brain/tools.rs that stages a typed workflow proposal (repo, merge target, rebase first, who reviews) with the quotes it rests on; it never saves.
- At turn end obid turns the staged list into 'Can I remember that?' items only when the turn completed; a stopped, failed or cut turn drops it.
- `source: "conversation"` on such suggestions; `widens`, the secret scan and the declined list (R12-10) run as today.

**Out:**
- Free-text preferences ('write tests with every fix'): they are agent context, which the CLI's own memory and CLAUDE.md hold (AGENTS.md, 'Dispatcher, not harness').

### Actors and ownership: what obid owns

- Staging, the turn-end rule and the save.

### Actors and ownership: what the apps show and send

- The existing 'Can I remember that?' inbox item.

### Interfaces and dependencies

- Suggestion `source`: new value `conversation` (add-only; check that no Swift client decodes it as a closed enum).

### Steps

- Add the tool schema next to oby_routine.
- Keep staged proposals on the turn in memory, not in a file.
- At turn completion, run `ask_workflow` for each; drop them on any other end.
- Test MEMORY-6 to 8.

### Acceptance scenarios

- MEMORY-6 (proposed): Given a turn that calls `oby_remember` and completes, when it ends, then one 'Can I remember that?' item with `source: conversation` is in the inbox and no memory file is written.
- MEMORY-7 (proposed): Given a turn that calls `oby_remember` and is stopped or fails, when it ends, then no item is made.
- MEMORY-8 (proposed): Given a staged proposal, when only POST /v1/memory/suggestions/{id}/remember with the owner's signed yes arrives, then it is saved; any other path saves nothing.
