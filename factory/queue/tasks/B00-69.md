Step 2 of the Agents plan (docs/decisions/2026-11-16-agents-follow-openbot.md). The largest piece: OpenBot's is about 16k lines. Build it in three pull requests under this task: (a) tabs and reading, (b) input, (c) secrets and takeover. OpenBot's code is not copied (PolyForm Noncommercial).

## What
An agent can't use a web page. It can only fetch text, and only when the web is granted. A browser comes only if the owner's own Claude Code already has a browser MCP server. OpenBot has a persistent browser inside the app that agents open and drive, and that the person watches, takes over and signs in to.

## Why
- **The owner, 2026-11-16:** "Follow exactly what OpenBot does!", answering whether a browser is offered by default.
- **Lane: dispatcher**, by that decision.

## How
1. **Where it runs.** The spec's first decision: a browser in the Electron app's main process (as OpenBot's), or one obid starts that the app shows. Either way, obid serves its tools to every agent, and the app shows the page live beside the agent's conversation.
2. **Tools, for every agent** (the owner's word):
   - (a) `oby_browser_open`, `list_tabs`, `snapshot` (the page as text and elements), `screenshot`, `wait_for`, `close_tab`.
   - (b) `navigate`, `click`, `type`, `fill_fields`, `press`, `scroll`, `select_option`, `upload_files` (from the agent's room only).
   - (c) `request_takeover` and `submit_secret`.
3. **Profiles.** One persistent profile per agent by default, kept in obid's home; "Shared" on the owner's choice.
4. **Takeover.** While the person holds a tab, the agent's tools are refused on it.
5. **Secrets.** A password or code goes in through a card in the app, straight into the field; it never passes through the model, a tool argument, a log or the transcript. Cookie banners are declined. CAPTCHAs, passkeys and 3-D Secure go to the person.
6. **Outside text.** Page text reaches the agent as quoted data and marks the turn untrusted (From outside); at Full access that brings no Confirm (B00-61).

A Kani harness over `may_act(tab_held_by_person, tool) -> bool`: false for every input tool while the person holds the tab.

Acceptance (each a test named after it):

2. AGENTBROWSER-2: an agent fills and submits a form on a local test page.
