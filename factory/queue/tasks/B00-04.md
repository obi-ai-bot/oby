## What
Typing `/` in the message box (Composer) opens a menu over it, as wide as the box, with the project's factory first, then the profile's agents, one title per connected agent tool (its account beside it) with that tool's skills and commands, routines, and Oby's own commands. It narrows as you type. Picking `/factory` opens its actions (B00-05).

## Why
- **The owner wants the factory and everything else reachable from the box** without leaving the conversation.
- **Nothing new to learn.** It is the `@` list's panel and keys (`Composer.tsx`, Sangam's), with the same token look.

## How
1. **When it opens (the owner's answer: "like T3 does"):** a word that starts with `/` opens it anywhere in the message; a word with a second `/` or a `\` is a path and opens nothing. As the very first character, it offers every group. Mid-text it offers only agents and Oby's `/model`. T3 Code: `packages/shared/src/composerTrigger.ts:50-62`, `apps/web/src/composerSlashCommandSearch.ts:15-31`, `useComposerMenuItems.ts:308-311`.
2. **Ranking:** exact, then prefix, word start, contains, fuzzy subsequence; the description counts less; ties go Oby, Factory, Agents, each tool, Routines. Matched letters bold. The empty menu shows at most 3 rows a group, with "N more" on the title.
3. **Keys:** ↑/↓ wrap, Tab or ↵ picks, → opens a row's own list, Esc closes and keeps the words.
4. **A pick:** an agent or a tool's command or skill inserts `/name ` as a token naming its source; `/factory` opens B00-05's actions; a routine runs (`POST /v1/routines/{id}/run`); Oby's commands call what the app already does (`/model` opens the talk pill, `/new` a new conversation, `/settings` Settings).
5. The words a person sees are Sangam's to change: the screens are in the canvas "Oby Tasks and Factory", screens 11 to 13, and docs/design/oby-slash-and-factory-settings/README.md.
