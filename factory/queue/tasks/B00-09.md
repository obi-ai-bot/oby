## What
Settings gets a Factory page: the project's chip, a Steps | JSON switch, four presets (Fast, Careful, Cheapest, Custom) each with its time and room, then each step under its stage (Prepare, Work, Check, Review, Merge) with an account picker (each account with the room left in its week), a model picker and the step's hint. The JSON tab shows `factory.json` as it is, checked as you type, the problem said on its line, Save off until it's valid.

## Why
- **The owner's idea:** the factory's settings as a JSON file changed visually with options, with the raw JSON for power users.
- **Cheapest keeps every gate** (the owner's question 10, researched 2026-11-15): no product lets a cheaper tier relax a merge gate, so Cheapest runs the second review cheaply on another tool (Cursor Auto) rather than skipping it.

## How
1. A new Settings page, `factory`, between Connectors and About, drawn as the canvas "Oby Tasks and Factory", screens 14 and 15 (docs/design/oby-slash-and-factory-settings/README.md, §3). Sangam's words lead.
2. Steps writes through `PUT /v1/projects/{id}/factory/settings` (B00-06); its pickers list `options`. Any change to a step marks the preset `custom`.
3. JSON checks with `PUT ?dryRun=1` as you type (debounced) and shows each problem on its line; Save is enabled only when there are none.
4. With two reviews on one tool, the Review card shows the line: "A security path merges by itself only after two reviews by different tools. With both on Claude Code, it waits for your click."
5. A stale save (409) reloads the file and says so.
