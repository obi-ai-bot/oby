## What
Someone with no GitHub can't use Oby's work: a folder with no remote can't run its own job (`file://` only behind a test flag), and nothing finishes there. As T3 Code does it, each conversation should choose where it works, **This folder** (the project's checkout, edited in place) or **A new worktree** (its own copy and branch), chosen at its start and kept after. Finishing offers what the folder can do: with a remote, Commit, Push, Create pull request; with no remote, only **Commit**, then **Publish repository** once everything is committed; a folder that isn't a git repository works in place and offers **Initialize Git**.

## Why
- **The top gap for someone with no GitHub** (the plan, §4).
- **The owner's answers (2026-11-15), questions 6 and 7: "follow what T3 does".** T3 Code: modes `local` and `worktree` (`packages/contracts/src/environment.ts:54`), labels "Current checkout" and "New worktree" (`apps/web/src/components/BranchToolbar.logic.ts:95-113`), default `local`; with no remote only Commit, then Publish repository (`GitActionsControl.logic.ts:147-149,288-308`); not a git repository, always local (`packages/shared/src/projectSettings.ts:210-215`). T3 has no local merge of a worktree branch, so neither does this.

## How
1. A conversation's workspace, `folder` or `worktree`, chosen with its first message (default `folder`), never changed after. A factory job always gets its own worktree, whatever the conversation chose, as T3 makes a worktree per model when one message goes to several.
2. Finishing: obid answers which actions the workspace can take (`commit`, `push`, `pullRequest`, `publishRepository`, `initializeGit`) from its remote and git state; the app shows them. Publish repository makes the remote on the code host signed in (GitHub today) and pushes. No gh call for a folder with no remote until the owner publishes it.
3. **A lanes change, the owner's word:** the owner's own Claude Code conversation writes only its room today (LANES-12), Codex's never `repos/` (CODEX-2). In `folder`, the conversation's commands may write that folder, and only that folder: the sandbox's write list is the folder, nothing else of the person's home. `docs/contracts/lanes.md` changes in this pull request. The five non-negotiables don't move: no secret, login or vault value reaches the folder.
4. A worktree is removed with its conversation, and once merged (as A00-69 does for jobs).
5. This touches what steers agents' sandboxes: a security path, so two reviews by different tools or the owner's click.
