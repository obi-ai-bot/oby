TITLE: fix(factory): oby-feed carries a task past a failed or interrupted job and a refused or conflicting head, up to three attempts, then ends it with obid's reason
MILESTONE: A00 Asked for outside the roadmap
SPRINT: 0
ORDER: 96
RISK: 
DESIGN: 
DEPENDS: none
FIXES: none

Contract: docs/contracts/factory.md. Models of record: docs/models/oby_factory.qnt, docs/models/oby_feed.qnt.

What. `factory/bin/oby-feed` (the factory inside Oby) starts one Oby job per task and follows it. Today, any end but `done` with a pull request is final for the task: `interrupted` (obid restarted three times, a stall after its five continuations, a session it couldn't resume), `failed`, a job obid no longer has (404), or `done` with nothing published all become `failed`. The task's key stays in the feed's state, so it is never started again. A head GitHub's merge queue refused, or one that conflicts with dev, goes to `waiting` with that head refused, and nothing ever makes a new head: obid's own rebase round runs only for heads obid armed itself, and oby-feed arms its own. A review that ran out of rounds also waits for a person.

Why. The owner wants the factory to run with nobody watching. Claude Code and T3 Code keep going on their own. T3 Code continues a run after a restart (`RestartContinuation.ts`: "Continue where you left off", at most 3 in 5 minutes) and retries what can pass later with a fixed cap. obid already does this inside a job (RECOVERY-1 to 4, a cap of 10). But one passing failure at the task level, such as obid being updated mid-run or dev moving under a pull request, ends that task's automation for good. The model below proves this: with the feeder as merged, a task never merges after any one of its jobs failed.

How. A task gets at most 3 attempts (a constant beside `--max`); each new job counts as one. When an attempt ends, the next pass does one of three things:
- **Start a new build job** for the task. This happens when the job ended `failed` or `interrupted`, was lost (404), or ended `done` without a pull request. The brief adds one line in obid's own words: the job's `status`, plus its `nextStep`, `publishError` or `waiting` text, cut to 300 characters. It never adds the agent's summary, GitHub's text, or check output (AGENTS.md, "From outside": outside text reaches agents only as quoted files). The new job uses its own new `clientRequestId`.
- **Send a follow-up on the same pull request**, using `POST /v1/jobs/{id}/messages` to the ended job, which starts a follow-up of the same kind, account and branch. This happens when GitHub's queue refused the armed head, when the pull request is `CONFLICTING`/`DIRTY` or `BEHIND` dev, or when Oby's review ran out of rounds asking for changes. The message uses fixed words for each case. For example: "GitHub's merge queue didn't merge <head>: rebase onto dev, run the check, and make the queue's Check pass; read the pull request's checks with gh."
- **End for good.** A `STATUS: BLOCKED` summary (the task can't be done as written), a job the owner stopped (`stopped`), and a security-path hold (`waiting` for the owner, as today) are never retried. Out of attempts, the task ends `failed`. Its note gives the last attempt's reason, and its jobs keep their worktrees for the owner to read (as today).

`--status` shows `attempt n of 3` for each task.

Add the model below as `docs/models/oby_feed_loops.qnt`, unchanged unless the design changes. Keep the rules in one function the tests call.

### Formal verification
Quint model `docs/models/oby_feed_loops.qnt` (below), verified with quint 0.33.1 on the gate VM on 2026-11-15.

`loops_merged` (oby-feed as on origin/dev, with A00-80):
- `attemptsBounded` and `neverMergedAfterAFailure` both hold. The second one is the gap: across every run of up to 12 steps, a task never merges once one of its jobs failed or was interrupted.
- `nothingOwed` is violated. Counterexample: the job ends `interrupted` (obid went down) → the pass marks the task `failed` with attempts left.

`loops_fixed` (the design above):
- `attemptsBounded`, `nothingOwed` and `endsWithReason` hold in every run of up to 16 steps.
- Its witnesses `neverMergedAfterAFailure` and `neverRebuilt` are violated: a task merges after a failure, and a rebuilt head merges. So the pass is not vacuous.

Acceptance (tests in `factory/tests/test_oby_feed.py`, each named after its scenario; obid's API and `gh` are stubbed):
1. FEEDLOOP-1: a job that ends `interrupted` with attempt 1 of 3 starts a new build job at the next pass. Its brief carries obid's reason and nothing from the agent's summary.
2. FEEDLOOP-2: a job lost (404), or `done` with nothing published, is started again the same way.
3. FEEDLOOP-3: a task whose head GitHub's queue refused sends one fixed message to its job, and follows the follow-up obid starts (`running`).
4. FEEDLOOP-4: a pull request that is `CONFLICTING` or `BEHIND` dev gets the same follow-up, with the rebase sentence.
5. FEEDLOOP-5: after the third attempt, the task ends `failed` with the last reason and starts nothing more.
6. FEEDLOOP-6: `STATUS: BLOCKED`, `stopped`, and a security-path hold are never retried.
7. FEEDLOOP-7: no brief or message carries text read from GitHub or the agent's summary (asserted on every message the tests send).

### The model
```quint
// verify: main=loops_merged steps=12 invariants=attemptsBounded,neverMergedAfterAFailure witnesses=nothingOwed
// verify: main=loops_fixed steps=16 invariants=attemptsBounded,nothingOwed,endsWithReason witnesses=neverMergedAfterAFailure,neverRebuilt
//
// The factory's outer loop, one task: factory/bin/oby-feed starts an Oby job, follows it to a pull request, arms
// GitHub's merge queue, and must keep the task moving with nobody watching. What can happen to it: the job ends
// failed or interrupted (a crash, obid restarting, rounds run out), the queue refuses the armed head (its Check fails
// on the combined code), or dev moves and the branch conflicts.
// nothingOwed: right after a feeder pass, the task is merged, is being worked on (a job running, a head in the queue,
//   reviews pending), or has ended for good with its reason: never parked where only a person can move it while
//   attempts are left.
// attemptsBounded: the feeder starts at most MaxAttempts jobs for one task (no endless loop).
// endsWithReason: a task that stopped for good carries the reason of its last attempt.
// loops_merged: oby-feed as on origin/dev (A00-80 merged): a job that ends anything but done-with-a-pull-request
//   makes the task `failed` for good; a refused or conflicting head waits for someone to push a new one.
//   Expected: nothingOwed is VIOLATED (a witness there), and neverMergedAfterAFailure HOLDS: one failed job ends the task.
// loops_fixed: a failed or interrupted job starts the task again with the last reason in its brief, and a refused
//   or conflicting head starts a follow-up on the same branch ("rebase onto dev, make the queue's Check pass"), each
//   while attempts are left; out of attempts it ends `failed` with the reason. Expected: all three hold.
// The limit: a model checks the design, not that the script implements it.

module loops_common {
  pure val MaxAttempts = 3
}

module loops_merged {
  import loops_common.*
  var st: str          // running, reviewing, merging, waiting, failed, merged
  var job: str         // running, done, failed, interrupted
  var pr: str          // none, open, merged
  var conflict: bool   // the branch conflicts with dev, or the queue's Check fails on the combined code
  var attempts: int
  var reason: str
  var failures: int    // jobs that ended failed or interrupted, for the witness
  var afterPass: bool

  action init = all { st' = "running", job' = "running", pr' = "none", conflict' = false, attempts' = 1,
                      reason' = "", failures' = 0, afterPass' = false }
  action keepFeed = all { st' = st, attempts' = attempts, reason' = reason }

  // ---- the world ----
  action jobEnds = {
    nondet out = Set("done", "failed", "interrupted").oneOf()
    all { job == "running", job' = out, pr' = if (out == "done" and pr == "none") "open" else pr,
          conflict' = false, failures' = if (out == "done") failures else failures + 1, keepFeed, afterPass' = false }
  }
  action devMoves = all { pr == "open", not(conflict), conflict' = true, job' = job, pr' = pr, failures' = failures,
                          keepFeed, afterPass' = false }
  // the queue merges a head that doesn't conflict
  action queueMerges = all { st == "merging", pr == "open", not(conflict), pr' = "merged", job' = job,
                             conflict' = conflict, failures' = failures, keepFeed, afterPass' = false }
  action world = any { jobEnds, devMoves, queueMerges }

  // ---- the feeder's pass as merged ----
  action pass = all {
    job' = job, pr' = pr, conflict' = conflict, failures' = failures, afterPass' = true, attempts' = attempts,
    if (st == "running" and job == "running") all { st' = st, reason' = reason }
    else if (st == "running" and job != "done") all { st' = "failed", reason' = job }
    else if (st == "running") all { st' = "reviewing", reason' = reason }
    else if (st == "reviewing") all { st' = if (conflict) "waiting" else "merging", reason' = reason }   // reviews pass
    else if (st == "merging" and pr == "merged") all { st' = "merged", reason' = reason }
    else if (st == "merging" and conflict) all { st' = "waiting", reason' = "the queue refused the head" }
    else if (st == "waiting" and pr == "merged") all { st' = "merged", reason' = reason }
    else all { st' = st, reason' = reason }
  }
  action step = any { world, pass }

  val inMotion = (st == "running" and job == "running") or (st == "merging" and not(conflict)) or st == "reviewing"
  val owed = not(st == "merged" or inMotion or (st == "failed" and attempts >= MaxAttempts))
  val nothingOwed = afterPass implies not(owed)
  val attemptsBounded = attempts <= MaxAttempts
  val neverMergedAfterAFailure = not(st == "merged" and failures > 0)
}

module loops_fixed {
  import loops_common.*
  var st: str
  var job: str
  var pr: str
  var conflict: bool
  var attempts: int
  var reason: str
  var failures: int
  var rebuilt: bool    // a follow-up was started to rebase or fix a refused head, for the witness
  var afterPass: bool

  action init = all { st' = "running", job' = "running", pr' = "none", conflict' = false, attempts' = 1,
                      reason' = "", failures' = 0, rebuilt' = false, afterPass' = false }

  action jobEnds = {
    nondet out = Set("done", "failed", "interrupted").oneOf()
    all { job == "running", job' = out, pr' = if (out == "done" and pr == "none") "open" else pr,
          conflict' = false, failures' = if (out == "done") failures else failures + 1,
          st' = st, attempts' = attempts, reason' = reason, rebuilt' = rebuilt, afterPass' = false }
  }
  action devMoves = all { pr == "open", not(conflict), conflict' = true, job' = job, pr' = pr, failures' = failures,
                          st' = st, attempts' = attempts, reason' = reason, rebuilt' = rebuilt, afterPass' = false }
  action queueMerges = all { st == "merging", pr == "open", not(conflict), pr' = "merged", job' = job,
                             conflict' = conflict, failures' = failures, st' = st, attempts' = attempts, reason' = reason,
                             rebuilt' = rebuilt, afterPass' = false }
  action world = any { jobEnds, devMoves, queueMerges }

  // again: a new job for the task (a fresh build when no pull request, else a follow-up on its branch)
  val left = attempts < MaxAttempts
  action pass = all {
    failures' = failures, afterPass' = true, pr' = pr,
    if (st == "running" and job == "running")
      all { st' = st, job' = job, conflict' = conflict, attempts' = attempts, reason' = reason, rebuilt' = rebuilt }
    else if (st == "running" and job != "done")
      if (left) all { st' = "running", job' = "running", conflict' = conflict, attempts' = attempts + 1, reason' = job, rebuilt' = rebuilt }
      else all { st' = "failed", job' = job, conflict' = conflict, attempts' = attempts, reason' = job, rebuilt' = rebuilt }
    else if (st == "running")
      all { st' = "reviewing", job' = job, conflict' = conflict, attempts' = attempts, reason' = reason, rebuilt' = rebuilt }
    else if (st == "merging" and pr == "merged")
      all { st' = "merged", job' = job, conflict' = conflict, attempts' = attempts, reason' = reason, rebuilt' = rebuilt }
    else if ((st == "reviewing" or st == "merging" or st == "waiting") and conflict)
      if (left) all { st' = "running", job' = "running", conflict' = conflict, attempts' = attempts + 1,
                      reason' = "the queue refused the head", rebuilt' = true }
      else all { st' = "failed", job' = job, conflict' = conflict, attempts' = attempts, reason' = "the queue refused the head", rebuilt' = rebuilt }
    else if (st == "reviewing")
      all { st' = "merging", job' = job, conflict' = conflict, attempts' = attempts, reason' = reason, rebuilt' = rebuilt }
    else all { st' = st, job' = job, conflict' = conflict, attempts' = attempts, reason' = reason, rebuilt' = rebuilt }
  }
  action step = any { world, pass }

  val inMotion = (st == "running" and job == "running") or (st == "merging" and not(conflict)) or st == "reviewing"
  val owed = not(st == "merged" or inMotion or (st == "failed" and attempts >= MaxAttempts))
  val nothingOwed = afterPass implies not(owed)
  val attemptsBounded = attempts <= MaxAttempts
  val endsWithReason = st == "failed" implies reason != ""
  val neverMergedAfterAFailure = not(st == "merged" and failures > 0)
  val neverRebuilt = not(rebuilt and st == "merged")
}
```
