What. obid keeps a list of profiles and shows nothing for it: every conversation, job, project, account, setting and vault secret is in one place, whatever the profile.

Why. The owner works for more than one company and wants each as a separate environment on one Mac, switched from one menu.

How. Each profile gets its own storage root under obid's home for conversations, jobs, projects, accounts, settings, permissions and the vault; what is Mac-wide (the API token, devices, the gateway) stays where PROF-2 put it. The first profile keeps everything an install already has, with nothing moved or signed out; its first name is "Default". Routes, add-only: POST /v1/profiles (name, colour), PATCH /v1/profiles/{id}, and a way to say which profile a request is for; a request that names none means the default one, so today's apps keep working. A profile's waiting flag is true exactly when something in it needs the owner. Switching moves nothing. A job runs on its own profile's accounts only.
