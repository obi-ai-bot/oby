## What
Three of obid's fixed sentences describe this repository, and every repository hears them:
- every agent is told to commit "with a Conventional Commits message" (`core/crates/obid/src/jobs.rs:14468`, and `COMMIT_HERE` at `jobs.rs:369`);
- every agent's prompt gives `cargo test --manifest-path core/Cargo.toml` as its example of naming paths (`jobs.rs:14486`);
- a job with no base and no pull request yet shows "Merged into dev" as its last stage (`core/crates/obid/src/job.rs:1921`).

## Why
- **The owner, 2026-11-16:** our rules aren't Oby's. Conventional Commits, `core/Cargo.toml` and `dev` are ours.
- **Agents already get the repository's own rules.** obid quotes the base's `AGENTS.md` and `CLAUDE.md` to them and tells them to follow its conventions for commits (`core/crates/obid/src/review.rs:261`, `rules_line`). A repository with another commit style gets two conflicting instructions today.
- **T3 Code keeps commit style per project** (`sourceControlWritingStyle`, `packages/contracts/src/settings.ts:1171-1192`).
- **Lane: dispatcher.** obid's own standing words to the agents. Nothing new is told to an agent; one sentence becomes conditional and one example becomes neutral.

## How
1. **`commitStyle` in `Rules`.** B00-27's `oby.json` may say `"commitStyle": "conventional"`. With it, obid's two sentences say Conventional Commits as today. Without it, they say a message that follows the repository's own rules for commits. Any other value is ignored and noted on the job: obid's standing words are only obid's own (`jobs.rs:14452-14458`), so a repository's text never goes into them. A style of a team's own goes in its `AGENTS.md`, which the agent already reads. Once B00-28 lands, its owner's layer can set `commitStyle` too.
2. **The example names no repository's layout:** a placeholder (`make -C <folder> test`), not a path in this repository.
3. **The last stage names the repository's own branch:** with no base and no pull request, `Merged into <defaultBranch>` from the repository's entry (`core/crates/obid/src/config.rs:205`), not `dev`.
4. **This repository's `oby.json`** gains `"commitStyle": "conventional"`, so its agents hear what they hear today.
5. obid's fixed prompt text only gets shorter; any guard on its size stays green.
6. `docs/contracts/repo-rules.md`: REPORULES-13 to 15. The test at `jobs.rs:17242` that expects "Conventional Commits" moves to the case with `commitStyle`.
