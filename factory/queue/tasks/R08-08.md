# chore(obid): delete the retired limit-decision store, answer its API from the hold table

<!-- Roadmap R08-08 · Sprint 4 · R08 One interface for every agent CLI · effort S · risk medium -->

### Sangam's screen

engine only

### Outcome

The code for the owner's limit cards (retired by LIMITS-15) goes, while `GET /v1/limit-decisions` and its answer route keep answering, so older apps keep working.

### Status and scope

Proposed (roadmap R08-08, milestone R08 One interface for every agent CLI).

**Why:** core/crates/obid/src/account_limits.rs (333 lines) keeps the #1563 decision store that LIMITS-3 and LIMITS-4 retired; account-limits.md says the Move code 'stays for the API, unexercised'. jobs/account_limits.rs keeps `limit_refreshed` and decision paths beside it.

**In:**
- Delete core/crates/obid/src/account_limits.rs and the decision paths in jobs/account_limits.rs.
- `GET /v1/limit-decisions` answers `[]`; `POST /v1/limit-decisions/{id}/answer` answers `409` for an id it does not have, with its signature checks kept.
- A pending decision file an older release left is resolved into holds at load (LIMITS-13).

**Out:**
- Removing the two endpoints (obid's API is add-only).
- Removing the `limitDecision` event key from clients.

### Actors and ownership: what obid owns

- The compatibility answer of the two limit-decision endpoints.

### Actors and ownership: what the apps show and send

- Nothing changes for clients: they already see no pending decision.

### Interfaces and dependencies

- `GET /v1/limit-decisions` always answers an empty list (same shape); docs/runner-api.md says so.

### Steps

- Add LIMITS-25 and 26; mark LIMITS-3 and 4 as deleted code, not just retired.
- Convert pending decisions to holds at load; delete the store.
- Make the endpoints answer as above; update docs/runner-api.md ~1052-1054.
- Trim limit_decisions_api.rs to the compatibility answers; keep the signature refusal tests.
- Lower `obid_lines_limit` by the lines removed.

- LIMITS-26 (proposed): Given a home with a pending decision an older release wrote, when obid starts, then its jobs move or wait as LIMITS-15 says, and no decision is listed (LIMITS-13 kept).
