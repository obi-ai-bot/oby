# refactor(obid): split acp.rs into a generic ACP client and a Cursor flavor

<!-- Roadmap R08-06 · Sprint 5 · R08 One interface for every agent CLI · effort M · risk low -->

### Sangam's screen

engine only

### Outcome

The ACP client speaks only the protocol; everything Cursor-specific is one `AcpFlavor` value whose hooks each name the cursor-agent version they were seen on. Another ACP agent later needs a flavor value and a table row.

### Status and scope

Proposed (roadmap R08-06, milestone R08 One interface for every agent CLI).

**Why:** acp.rs (1,650 lines) handles `cursor/update_todos`, `cursor/task`, `cursor/create_plan` and `cursor/ask_question` inside the generic request loop (~910-1016); `pub mod cursor` (1064) holds `--sandbox disabled`, `CURSOR_CONFIG_DIR`, the socket-length check and `.cursor/cli.json`. #1093 (Gemini via ACP) found the adapter generic in name only.

**In:**
- `struct AcpFlavor` of optional hooks: `argv`, `env`, `on_request(method, params) -> Option<Reply>`, `error_words`, `load_session` handling; each hook with a `seen_on` version string.
- `cursor` as the first and only value; the generic loop refuses any unknown request (as today).

**Out:**
- A Gemini or Antigravity flavor (#1093).
- Cursor's lane (stays boxed, AGENTS.md).

### Actors and ownership: what obid owns

- The ACP protocol client and the per-agent extensions it accepts.

### Actors and ownership: what the apps show and send

- Move `pub mod cursor` to acp/cursor.rs; keep `cursor_folder_tests` passing.
- Add PROVIDERS-11 to 13; run `cargo test -p obid --test adapters`.

### Acceptance scenarios

- PROVIDERS-11 (proposed): Given a Cursor job (stand-in), when it sends `cursor/create_plan`, `cursor/ask_question`, `cursor/update_todos` and `cursor/task`, then obid answers each as today, through the Cursor flavor.
- PROVIDERS-12 (proposed): Given the generic ACP client with no flavor hooks, when an agent sends a `cursor/` request, then obid refuses it and the turn goes on.
- PROVIDERS-13 (proposed): Given the Cursor flavor, when a reader lists its hooks, then each names the cursor-agent version it was observed on.
