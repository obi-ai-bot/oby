# feat(obid): `obid sphere enroll` joins a Sphere from a one-time bundle on stdin

<!-- Roadmap R12-16 · Sprint 10 · R12 Developer workflows · effort M · risk medium -->

### Sangam's screen

engine only

### Outcome

A Linux obid becomes a Sphere member from one command, with no secret on the command line or in the environment.

### Status and scope

Proposed (roadmap R12-16, milestone R12 Developer workflows).

**Why:** Today only POST /v1/obid/sphere/join, called by the Electron app, joins a Sphere, so a Linux obid cannot be a member.

**In:**
- `obid sphere enroll --config <path>`: read one JSON bundle from stdin (never argv or environment) with the Sphere link, the owner-signed card for this obid's Obi key and a delegation; check them as `join` does.
- Refuse a bundle for another Obi key, an expired one, or one already used.
- `obid sphere renew --config <path>` with a renewal bundle on stdin, as the spike decides.

**Out:**
- The Mac's dialog that makes the bundle (needs Sangam's design; a follow-up the spike names).
- Machine linking (#1284).

### Actors and ownership: what obid owns

- The bundle checks, the used-bundle record and the join.

### Actors and ownership: what the apps show and send

- Nothing changes for clients.

### Files

- core/crates/obid/src/main.rs
- core/crates/obid/src/sphere/link.rs

### Steps

- Add `sphere enroll` and `sphere renew` to main.rs's parser with its tests.
- Call the same join logic that `sphere::routes::join` uses; do not copy it.
- Record used bundle ids in the Sphere folder.
- Test SPHERE-8 to 11 with a test signer.
- Document the headless steps in docs/install.md.

### Acceptance scenarios

- SPHERE-8 (proposed): Given a bundle signed for this obid's Obi key, when `obid sphere enroll` reads it from stdin, then obid joins as SPHERE-1 says and prints no secret.
- SPHERE-9 (proposed): Given the same bundle a second time, or one for another Obi key, when enroll runs, then nothing is joined and it says why.
- SPHERE-10 (proposed): Given a bundle in argv or an environment variable, when enroll runs, then it is not read.
- SPHERE-11 (proposed): Given a membership with 5 days left and a renewal bundle on stdin, when `obid sphere renew` runs, then the delegation is replaced with the same scope.

Contract: docs/contracts/obysphere.md (existing, prefix SPHERE, last SPHERE-7)

### Tests

### Done when

- On a Linux box, enroll with a bundle made by a test signer; the Mac lists the box as a member.
