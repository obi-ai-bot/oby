# test(relay): phones read a session that obid's envelope tests record

<!-- Roadmap R07-08 · Sprint 3 · R07 One wire contract · effort S · risk low -->

### Sangam's screen

engine only

### Outcome

A change to the relay envelope on any side fails the other sides' tests, because they all read one recorded session.

### Status and scope

Proposed (roadmap R07-08, milestone R07 One wire contract).

**Why:** core/crates/obid/src/relay/envelope.rs has the known answer (the_envelope_gives_its_known_answers); apps/ios/tests/RelayTests.swift (790 lines) and apps/android/.../RelayTest.kt (265 lines) re-implement obid's side from the text in docs/runner-api.md ('The envelope (version 1)').

**In:**
- An envelope test in obid writes new: docs/contracts/wire/relay-session.json: keys, hello, welcome, one request and answer, a counter gap and the reset
- RelayTests.swift reads that file instead of its own copy of obid's side
- Kotlin RelayTest reads it (skip this step if R03 freezes Android)
- runner-api.md points to the file as the known answer

**Out:**
- Any change to the envelope itself

### Actors and ownership: what obid owns

- The recorded session is written by obid's tests.

### Actors and ownership: what the apps show and send

- Nothing changes for clients.

- Write the recorder in envelope.rs tests with fixed keys.

- Prove WIRE-11 red by changing one byte.
