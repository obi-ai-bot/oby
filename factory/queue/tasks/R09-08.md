# feat(obid): a run marker, start attempts per version, and a runtime stall probe

<!-- Roadmap R09-08 · Sprint 8 · R09 Ship and debug safely · effort M · risk low -->

### Sangam's screen

engine only

### Outcome

obid knows, at each start, whether its last run ended cleanly, how many starts of this version failed in a row, and when its runtime was blocked. These go into the diagnostics bundle and, for a crash, the existing crash failure record.

### Status and scope

Proposed (roadmap R09-08, milestone R09 Ship and debug safely).

**Why:** Only jobs leave a clean-stop marker (`stopped-cleanly`, jobs.rs:104, 1147, 6249). A crash loop under launchd (KeepAlive SuccessfulExit false in apps/electron/build/com.deskree.oby.electron.obid.plist) leaves only obid.log lines; nobody counts failed starts, and a blocked tokio runtime leaves no trace.

**In:**
- home/run-marker: `running` with a 60 s heartbeat time, then `quitting`, `clean` or `quit_timeout`, written synchronously; a start that finds `running` or `quitting` records an unclean exit.
- home/start-attempts.json: per version, failed starts in a row; reset once obid listens and has run 60 s.
- A stall probe: a task that measures its own wake-up delay and records a stall of 1 s or more (count and longest) in memory and in the diagnostics bundle.
- An unclean exit makes the existing `crash` failure record; an inbox item only if #911 has landed it.

**Out:**
- The app's own marker (R09-09).
- Replacing `stopped-cleanly` in jobs.rs: keep it; the run marker sits beside it.

### Actors and ownership: what obid owns

- The marker, the counter, the stall numbers, and the crash record.

### Actors and ownership: what the apps show and send

### Steps

- Write run_marker.rs with synchronous writes (`store::write_private`) and a heartbeat on an existing tick.
- Read and update start-attempts.json before `serve` listens; reset after 60 s of running.
- Add the stall probe as one tokio task with a 250 ms sleep that measures lateness.
- Feed an unclean exit into failures.rs's `crash` trigger.
- Write RECOVERY-18 to 21 in tests/startup.rs (kill the real binary for 18).

### Acceptance scenarios

- RECOVERY-18 (proposed): Given obid was killed while running, when it starts, then it records one unclean exit with the last heartbeat time.
- RECOVERY-19 (proposed): Given obid stopped through its own shutdown, when it starts, then no unclean exit is recorded.
- RECOVERY-20 (proposed): Given three starts of one version that exit before listening, when the fourth start reads start-attempts.json, then it counts 3; a start that runs 60 s resets it to 0.
- RECOVERY-21 (proposed): Given the runtime is blocked for 2 s, when the probe wakes, then one stall of about 2 s is recorded.
