# refactor(obid): make Job.status private to the job module

<!-- Roadmap R04-08 · Sprint 7 · R04 One owner for job state · effort M · risk medium -->

### Sangam's screen

engine only

### Outcome

A new `job.status = ...` anywhere but job/lifecycle.rs no longer compiles, so the next fix cannot bring back a second writer.

### Status and scope

Proposed (roadmap R04-08, milestone R04 One owner for job state).

**Why:** After R04-07 every write goes through lifecycle, but `pub status` (job.rs:357) still lets any module write it. There are about 200 reads across jobs.rs, push.rs, merge.rs, brain/briefing.rs and sphere/link.rs, and test modules set it directly (job.rs tests, merge.rs:2405, push.rs tests).

**In:**
- Make `status` private (no `pub`); add `pub fn status(&self) -> Status`.
- Replace reads with `status()`.
- A test-only constructor for fixtures, for example `Job::fixture(status)` under #[cfg(test)] in job.rs, plus a #[doc(hidden)] one for integration tests that build Job values.

**Out:**
- phase, waiting, stalled and parked (they stay pub; a later task may fold them into one JobState).
