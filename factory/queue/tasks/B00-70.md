## What
An agent can't use the Mac's other apps. OpenBot gives every agent Computer Use through a bundled `cua-driver` (MIT), on unless switched off for one agent ("absent means on").

## Why
- **The owner, 2026-11-16:** "Follow exactly what OpenBot does!", answering whether Computer Use is offered by default.
- **Lane: dispatcher**, by that decision.

## How
1. **The driver.** Bundle a pinned `cua-driver` in the app (check its licence is MIT before bundling, and record it in NOTICE). obid runs one daemon of it, so macOS's Accessibility and Screen Recording grants attach to Oby once. The owner grants those in System Settings; Oby opens the page and never changes them itself.
2. **Every agent gets it.** Each agent's run gets the driver's MCP entry, unless the agent's `computerUse` is false (add-only; absent means on).
3. **What asks.** By level (B00-61): Full accepts each tool without a card, Ask first shows a card per action, Workspace only shows a card. A screen capture always asks, at every level.
4. **The switch.** In the agent's sheet, with Sangam's words.
