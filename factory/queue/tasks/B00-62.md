Step 1 of the Agents plan (docs/decisions/2026-11-16-agents-follow-openbot.md).

## What
Screen 09 shows an agent that works "Every weekday at 9:00 AM". On obid that line is mock data (`MOCK_SCHEDULE`, `apps/electron/src/renderer/src/mock.ts`), and a routine can only start a job in a repository (`docs/api/routines.md`). An agent can't act by itself at a time. OpenBot's agents can: a routine is a saved instruction for an agent, with a schedule, which the person or the agent sets.

## Why
- **The owner, 2026-11-16:** Agents follow OpenBot's agents for general work.
- **Lane: dispatcher.** When to start a turn is the dispatcher's; the turn is the agent's.

## How
1. **A routine's target.** A routine gains an add-only `helper` (an agent's id), instead of `repo` and `kind`. Such a routine's run is one turn of that agent's conversation, on its instructions, with the routine's `task` as the words, marked as the routine's (never the owner's signed words).
2. **Schedules.** The routines' existing schedules and `when` words (`Weekdays at 9:00` …). One run at a time per agent; a run due while one is going is skipped and said, never queued twice.
3. **Who sets it.** The owner (`POST /v1/routines`), or the agent itself through `oby_routine`, for its own conversation only, as in OpenBot. A routine an agent made is listed as made by it.
4. **What shows.** The agent's title bar shows the schedule from `when` instead of the mock, and the conversation shows "Ran at 9:00" before the run's turn.
5. **Its level.** A run has the agent's level (B00-61 when built; today's own lane until then).
