# feat(obid): a move says which MCP servers the new run loses

<!-- Roadmap R11-11 · Sprint 10 · R11 Connections: MCP, sign-in and the vault · effort S · risk low -->

### Sangam's screen

uses an existing screen: the job's line where moves already show (apps/electron/src/renderer/src/TaskView.tsx); words to confirm with Sangam

### Outcome

When a job moves to another tool or account (LIMITS-15, POST /v1/jobs/{id}/move), its line names the MCP servers the first run had and the new one doesn't, so the owner is told instead of finding out later.

### Status and scope

Proposed (roadmap R11-11, milestone R11 Connections: MCP, sign-in and the vault).

**Why:** An own-lane Claude Code run has the owner's own servers (LANE-12); a move to Cursor or into the box loses them silently. obid reads Claude Code's init event (agent.rs:614) but keeps only session_id and apiKeySource, not its mcp_servers list.

**In:**
- Keep the server names from Claude Code's init event (and Codex's or Cursor's equivalent if they report one) on the job.
- At a move, compare with what the new run gets (registry rows plus the new CLI's own, if known) and add 'without <names>' to the move's line.

**Out:**
- Copying any CLI config to the new run (dispatcher, not harness).

### Actors and ownership: what obid owns

- Which servers a run had, and the move's line.

### Actors and ownership: what the apps show and send

- The job's existing line shows the longer text; no new field to decode.

### Steps

- Read mcp_servers names from the init event in agent.rs; save them on the job.
- In jobs/moves.rs, compute the lost names at the move and add them to the line.
- Add LIMITS-21 and 22 with fake-claude's init event.

### Acceptance scenarios

- LIMITS-21 (proposed): Given a Claude Code job whose init event listed servers a and b, when it moves to Cursor and the new run gets only the registry's a, then the job's line says it moved and lists b as not available there.
- LIMITS-22 (proposed): Given a move where the new run gets every server the first had, when the line is written, then it names no lost server.

Contract: docs/contracts/account-limits.md (existing, prefix LIMITS; last LIMITS-20)
