## What
- When two learned values overlap in a text (one's last bytes are the other's first), `Secrets::redact`, `Secrets::try_redact` and `Snapshot::redact` take out the first and leave the rest of the second in the output, outside every `[redacted: …]` marker.
- Found by V01-05's bounded-exhaustive test `logs_1_no_part_of_overlapping_values_is_left` (`core/crates/obid/src/secrets.rs`, `mod tests`), which is ignored as `finding V01-43` until this lands.
- **Counterexample, in the code's words:** a `Secrets::default()` learns `x` = `aaaaaaaa` and `y` = `abaaaaaa`, which overlap by one byte (k = 1). The text is `caaaaaaaabaaaaaac`. `needles_of` puts `x`'s plain needle `aaaaaaaa` before `y`'s `abaaaaaa` (both 8 bytes, a tie kept in name order), so `replace` takes `x` first and writes `c[redacted: x]baaaaaac`. `y`'s needle is no longer there whole, and `runs()` finds no run of 16 to judge, so the output is `c[redacted: x]baaaaaac`: seven of `y`'s eight bytes, `baaaaaa`, are left outside the marker. `Secrets::redact`, `try_redact` and `Snapshot::redact` give the same. Reproduce: `cd core && cargo test -p obid --lib secrets::tests::logs_1_no_part_of_overlapping_values_is_left -- --ignored`.
- **Harm:** part of a vault value or a login lands in obid's log, an answer or an event (LOGS-1, VAULT-4). A second value that overlaps a first by k bytes leaves 8−k or more of its own bytes, a shorter guess for whoever reads the log.

## Why
`redacted` (`secrets.rs`) runs `replace` once per needle, in `needles_of`'s order (longest first, ties in name order). Each `replace` writes its marker in place of its match, so a later needle whose match overlapped the earlier one's can no longer be found whole, and its bytes outside the earlier match stay. Property 1 (no form left whole) still holds; property 2 (no byte left) doesn't.

## How
- Find every needle's matches in the text first, merge the spans that overlap or touch into one, and write one marker per merged span naming every value in it (`[redacted: x, y]`, as `marker` already writes for several names). Then the `runs()` pass as today.
- Keep `needles_of`'s order for which match a base64 `run` needle widens, and keep the case-insensitive matching `any_case` asks for.
- Remove `#[ignore = "finding V01-43"]` from `logs_1_no_part_of_overlapping_values_is_left`, so the test runs in the check, and drop V01-43 from `.claude/skills/verify-redaction/SKILL.md`'s open findings.
