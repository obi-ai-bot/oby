# feat(electron): wire Sangam's Home Routines group to /v1/routines

<!-- Roadmap R12-06 · Sprint 9 · R12 Developer workflows · effort S · risk low -->

### Sangam's screen

uses an existing screen: apps/electron/src/renderer/src/tasks.ts (`routines` group) and apps/electron/src/renderer/src/GroupView.tsx

### Outcome

The owner sees their real routines in Sangam's Routines group, runs one now and pauses one. obid's routines are no longer an API that no Mac client reaches.

### Status and scope

Proposed (roadmap R12-06, milestone R12 Developer workflows).

**Why:** tasks.ts has the `routines` group but fills it only from mock.ts (o1 to o4) and only with `?everything`; live.ts already handles routine turns and `routine` inbox items.

**In:**
- GET /v1/routines, the `routine` SSE event, Run now and the pause switch (`enabled` on PATCH) through apps/electron/src/main/obid.ts.
- Show obid's `when`, `lastRun.reason` and skip or miss words as obid sends them.

**Out:**
- A new screen or new words: Sangam's group only.
- Showing the group in the lean build: it stays behind `everything` until the owner says (lean.ts).

### Actors and ownership: what obid owns

- Everything about runs, skips and pauses.

### Actors and ownership: what the apps show and send

- The list, Run now and the pause switch in the existing group.

### Files

- apps/electron/src/main/obid.ts
- apps/electron/src/renderer/src/live.ts
- apps/electron/src/renderer/src/tasks.ts
- apps/electron/src/renderer/src/GroupView.tsx
- apps/electron/src/shared/obid-wire.ts
- new: apps/electron/src/renderer/src/test/routines.test.ts

### Steps

- Add the routine type to obid-wire.ts (generated if R07 landed).
- Read GET /v1/routines on start and apply `routine` events in live.ts.
- Map each routine to the group's row shape without new words.
- Wire Run now and the pause switch through obid.ts.
- Test ROUTINES-14 and 15 on the mock and a stub obid.

### Acceptance scenarios

- ROUTINES-14 (proposed): Given obid has two routines, when Home's Routines group opens, then it lists both with obid's `when` and last run, and a `routine` event updates a row in place.
- ROUTINES-15 (proposed): Given a routine, when the owner clicks Run now or the pause switch, then the app calls POST /v1/routines/{id}/run or PATCH `enabled`, and shows obid's 409 or 422 text as is.

Contract: docs/contracts/routines.md (existing, prefix ROUTINES)

### Tests

- routines_14_the_group_lists_obids_routines, routines_15_run_now_and_pause_call_obid (new, in apps/electron/src/renderer/src/test/routines.test.ts)

### Done when

- `npm run typecheck` and the tests pass.
- On a real Mac with `?everything`, a routine made with oby_routine shows and runs.
