# feat(obid): a routine run can carry a payload, quoted as data

<!-- Roadmap R12-03 · Sprint 9 · R12 Developer workflows · effort S · risk medium -->

### Sangam's screen

engine only

### Outcome

A CI step or git hook hands a routine an event (exit code, log path, failing test) and the job reads it as quoted data. No webhook is needed for local events.

### Status and scope

Proposed (roadmap R12-03, milestone R12 Developer workflows).

**Why:** POST /v1/routines/{id}/run (routines.rs `run`, line 1165) takes no body, so a script cannot tell a routine what happened.

**In:**
- An optional body `{"payload": string}` of at most 4,000 characters on POST /v1/routines/{id}/run.
- Mask it with the secret scan, then write `.obi/inputs/event-<run>.md` in the job's worktree, fenced with a nonce as ISSUETASK-1 quotes an issue; the prompt only names the file.
- Mark the job as having read outside text, as other quoted input does.
- `oby routine run <id> --payload -` in the CLI.

**Out:**
- A scheduled run with a payload: only Run now takes one.
- Any webhook (R12-16).

### Actors and ownership: what obid owns

- Size check, scan, the quoted file and the untrusted mark.

### Actors and ownership: what the apps show and send

- Nothing changes for clients: the apps' Run now sends no body.

### Interfaces and dependencies

- POST /v1/routines/{id}/run: optional body `{"payload": string}` (add-only).

### Steps

- Parse the optional body in `routines::run`; an empty body behaves as today.
- Pass the payload through `Routine::job` into NewJob as a quoted input; reuse the issue-quote writer, not a copy.
- Set the job's untrusted mark where other quoted input sets it.
- Add `--payload -` to `oby routine run`.
- Document it in runner-api.md, 'obid only: routines (#395)'.

### Acceptance scenarios

- ROUTINES-5 (proposed): Given a routine, when Run now arrives with a payload, then the job's worktree has `.obi/inputs/event-<run>.md` with the payload in a nonce fence, the prompt holds none of its words, and the job is marked untrusted.
- ROUTINES-6 (proposed): Given a payload over 4,000 characters, or one the secret scan cannot read, when Run now arrives, then it answers 422 or masks the finding, and a payload whose scan cannot run starts no job.

Contract: docs/contracts/routines.md (existing, prefix ROUTINES, last ROUTINES-4)
