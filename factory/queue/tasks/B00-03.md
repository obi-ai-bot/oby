## What
Claude Code and Codex each have their own commands (`/review`, `/compact`, `/init`) and the owner's skills (`.claude/skills/<name>/SKILL.md`, Codex's `skills/list`). Oby can't list them or offer them. obid should record, per tool, account and folder, what each CLI says it has, and pass words that start with one of them to that CLI exactly as typed.

## Why
- **The skills are the owner's and the CLI's.** Oby offers them; it never copies or runs them itself (AGENTS.md, "Dispatcher, not harness").
- **The owner's answer (2026-11-15):** "create a title and put them under it. Only show based on what is connected." Every connected tool gets its own title in the menu, a tool added later (Gemini) the day it's connected.
- T3 Code does the same: it asks Claude for its commands and Codex for its skills, and reads nothing it doesn't need (`apps/server/src/provider/ClaudeProvider.ts:536,600`; `CodexProvider.ts:735`).

## How
1. **Spike first:** does Claude Code's stream-json `system`/`init` event list its commands and skills in `-p` mode, as the SDK's initialization result does? Write the answer in the PR. If it doesn't, read only the names and `description` frontmatter of `.claude/skills/*/SKILL.md` and `.claude/commands/*.md` in the project and the account's own folder, for own-lane runs only.
2. Codex: `skills/list` on the `codex app-server` obid already runs (`core/crates/obid/src/codex.rs`). Cursor: nothing until it reports something.
3. Keep each report in the profile's home, per `(tool, account, folder)`: names, descriptions and argument hints only, never a file's body, at most 200 per tool, refreshed at each session start, with `seenAt`.
4. Built-in commands that only work in the tool's terminal (`/login`, `/logout`, `/exit`, `/config`, `/vim`, `/terminal-setup`) are filtered by a short list kept with the provider's description (R08's table when it lands).
5. Words to an own-lane conversation that start with `/<name>` of a reported command or skill reach that tool's CLI unchanged; obid adds no context block to that turn. A conversation talking through another tool runs that one turn on the command's tool, on the account the report came from.
6. Boxed runs never get the reported skills' folders (core/AGENTS.md, "Logins and secrets").
