# feat(electron): Help › Export Diagnostics… and Report a Problem…

<!-- Roadmap R09-07 · Sprint 8 · R09 Ship and debug safely · effort S · risk low -->

### Sangam's screen

uses an existing screen: the app menu in apps/electron/src/shared/menu.ts (a menu item, not a new screen)

### Outcome

The owner saves the diagnostics bundle to a file they choose and opens a prefilled GitHub new-issue page with only versions in it; they attach the file and submit themselves.

### Status and scope

Proposed (roadmap R09-07, milestone R09 Ship and debug safely).

**Why:** There is no way in the app to get state out for a report; shared/menu.ts has no Help menu items of Oby's.

**In:**
- shared/menu.ts: a Help menu with Export Diagnostics… and Report a Problem….
- Main calls GET /v1/diagnostics, adds the app's own version and update state, and writes the file with mode 0600 to the path from a save dialog.
- Report a Problem opens one fixed URL, https://github.com/obi-ai-bot/oby/issues/new, with only app and obid versions in the query; nothing is sent by Oby.

**Out:**
- A Diagnostics group in Settings (needs Sangam's design, #919).

### Actors and ownership: what obid owns

- The bundle (R09-06).

### Actors and ownership: what the apps show and send

- Two Help menu items, a save dialog, and the browser on GitHub's new-issue page.

### Files

- apps/electron/src/shared/menu.ts
- apps/electron/src/main/index.ts
- apps/electron/src/main/obid.ts
- new: apps/electron/src/main/diagnostics.ts
- new: apps/electron/src/renderer/src/test/diagnostics.test.ts

### Steps

- Add the Help items to menu.ts.
- Write main/diagnostics.ts: fetch through `obid()`, merge the app part, `dialog.showSaveDialog`, write 0600.
- Build the issue URL from a fixed base and two version strings; open it with `shell.openExternal`.
- Write DIAG-6 to 8 with Electron and obid stood in, as wake.test.ts does.

### Acceptance scenarios

- DIAG-6 (proposed): Given the owner chooses Export Diagnostics… and a path, when obid answers, then the file is written there with mode 0600 and nothing goes over the network.
- DIAG-7 (proposed): Given obid does not answer, when the owner exports, then the file holds the app's own part and says obid did not answer.
- DIAG-8 (proposed): Given Report a Problem…, when it opens the browser, then the URL is the fixed new-issue address and holds only version numbers.
