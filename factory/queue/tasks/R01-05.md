# test(obid): fail the check when a route goes, or a client calls one obid does not serve

<!-- Roadmap R01-05 · Sprint 1 · R01 Safety net · effort S · risk low -->

### Sangam's screen

engine only

### Outcome

Removing a route that the iPhone, Watch, Electron app or oby-mcp still calls fails the check, and a gateway allowlist entry with no route fails too.

### Status and scope

Proposed (roadmap R01-05, milestone R01 Safety net).

**Why:** obid's API must stay add-only (AGENTS.md 'How we work'), but nothing checks it except tests/swift_client.rs on macOS. Routes are declared by .route( calls in api.rs (97) and nine other modules; gateway.rs:69 keeps its own ROUTES list. 53 client files under apps/electron/src, apps/shared and mcp/ build /v1/ paths.

**In:**
- A committed list docs/api/routes.txt (method and path, sorted) generated from the .route( declarations
- A Rust test that regenerates it and fails on any difference, so a removal shows in review
- A Rust test that extracts /v1/ paths from apps/electron/src, apps/shared and mcp/ and fails when one has no route
- The same test for gateway.rs ROUTES; delete dead entries it finds

**Out:**
- Request and response keys and enum values (R07)
- Frozen client decoders (R07)

### Actors and ownership: what obid owns

- Nothing new at runtime.

### Actors and ownership: what the apps show and send

- Nothing changes for clients.

### Files

- new: core/crates/obid/tests/routes_guard.rs
- new: docs/api/routes.txt
- core/crates/obid/src/gateway.rs
- scripts/oby-check.sh
- scripts/oby-check-test.sh

### Steps

- Write routes_guard.rs: scan core/crates/obid/src/**/*.rs for .route("<path>", <method>(...)) and build the sorted list; compare it with docs/api/routes.txt.
- Extract client paths: string literals and template strings starting with /v1/ in apps/electron/src (TS), apps/shared (Swift), mcp/ (Swift); normalise {id} and ${...} segments to one wildcard.
- Check gateway.rs ROUTES against the list; delete entries with no route in the same PR.
- Map api.rs, gateway.rs and any client path change to this binary in scripts/oby-check.sh's planner.
- Add a failing and a passing case to scripts/oby-check-test.sh or as fixtures the test reads.

### Acceptance scenarios

- CI-9 (proposed): Given a change that removes a route from obid, when the check runs, then it fails and names the route.
- CI-10 (proposed): Given a client file that calls a /v1/ path obid does not serve, when the check runs, then it fails and names the file and path.
- CI-11 (proposed): Given a gateway.rs ROUTES entry with no route, when the check runs, then it fails and names the entry.

Contract: new: docs/contracts/ci.md
