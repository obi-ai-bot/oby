# feat(process): signed Linux obid archives in the release, and a timer that updates at an idle point

<!-- Roadmap R09-16 · Sprint 8 · R09 Ship and debug safely · effort M · risk medium -->

### Sangam's screen

engine only

### Outcome

Each release also publishes obid for Linux x86_64 and arm64, signed with the release key whose public half install.sh carries. A Linux obid updates itself daily, only when no worker and no turn runs.

### Status and scope

Proposed (roadmap R09-16, milestone R09 Ship and debug safely).

**Why:** docs/install.md: 'nothing is published there yet' and 'A checksum from the same host catches a broken download, not a forged one'; 'obid doesn't update itself yet (#456)'. Linux installs are hand-built and drift from the Mac's obid.

**In:**
- release.yml builds `obid-linux-{x86_64,arm64}.tar.gz` and signs each checksum with the release key.
- install.sh verifies the signature with a pinned public key before installing; `--archive` without a signature needs `--sha256` as today.
- install.sh installs a systemd user timer that stages a newer archive daily and installs it only when GET /v1/status shows `restart.ready` true.
- install.sh refuses an older archive than the installed one unless `--downgrade` is given (replacing today's warning).

**Out:**
- A home format stamp (not confirmed to exist; see unknown).

### Steps

- Add the Linux builds and signing to release.yml.
- Add signature verification to install.sh with the pinned public key.
- Write the timer and its service; the service reads restart.ready with the runner token.
- Change the older-archive warning to a refusal with --downgrade.
- Write LINUX-3 to 6 in tests/install.rs with a test key.

### Acceptance scenarios

- LINUX-3 (proposed): Given an archive whose signature does not verify, when install.sh runs, then nothing is installed.
- LINUX-4 (proposed): Given a newer archive and status.restart.ready false, when the timer fires, then it stages the archive and does not restart obid.
- LINUX-5 (proposed): Given the staged archive and restart.ready true, when the timer fires, then obid is replaced and restarted, and its home and token are kept.
- LINUX-6 (proposed): Given an archive older than the installed obid, when install.sh runs without --downgrade, then it refuses.
