# feat(obid): quarantine files that do not read, and report them

<!-- Roadmap R02-12 · Sprint 2 · R02 Commands that are safe to repeat · effort S · risk low -->

### Sangam's screen

engine only

### Outcome

A job, conversation or inbox file that obid cannot read is kept aside and named in status, not silently dropped from the list.

### Status and scope

Proposed (roadmap R02-12, milestone R02 Commands that are safe to repeat).

**Why:** store::load_dir (store.rs:89) logs and skips a file that does not parse. Callers: Store::load_all (jobs), Conversations::open (conversation.rs:472), Inbox::load_all, sphere/exchange.rs, routines.rs:411, groups.rs:249, failures.rs. A job skipped this way vanishes from every app.

**In:**
- load_dir moves an unreadable file to home/unreadable/<folder>/<name>-<time>.json.
- GET /v1/status `unreadable`: [{path, error, since}].

**Out:**
- Repairing the file.
- A UI for it (needs Sangam's design).

### Actors and ownership: what obid owns

- The quarantine folder and the list.

### Actors and ownership: what the apps show and send

- Nothing until Sangam designs a place for it; the status key is there for a later screen.

### Interfaces and dependencies

- GET /v1/status: `unreadable` list (add-only).

### Files

- core/crates/obid/src/store.rs
- core/crates/obid/src/api.rs
- core/crates/obid/tests/status.rs
- docs/runner-api.md

### Steps

- Give load_dir the home so it can move files; move with rename, never delete.
- Keep a list in memory filled at load and from the folder at start.
- Add `unreadable` to Status (api.rs:612).
- Write HOME-8 and 9.

### Acceptance scenarios

- HOME-8 (proposed): Given a job file that is not valid JSON, when obid starts, then the file is in home/unreadable/jobs/ with its bytes unchanged and GET /v1/status lists it.
- HOME-9 (proposed): Given a file in home/unreadable/, when obid starts again, then it is not loaded and still listed.

Contract: new: docs/contracts/home.md (prefix HOME)

### Tests

- home_8_an_unreadable_job_is_kept_aside
- home_9_a_quarantined_file_stays_listed (new, core/crates/obid/tests/status.rs)

### Done when

- Both tests pass.
- scripts/oby-check.sh passes.
