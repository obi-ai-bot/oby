# docs: a decision log in docs/decisions/, one file per owner decision

<!-- Roadmap R13-02 · Sprint 2 · R13 How we work · effort M · risk low -->

### Sangam's screen

engine only

### Outcome

Each dated owner decision has a short file: date, the owner's words, what it replaced, the contracts and scenarios it changed, and a superseded-by link. History becomes one click away instead of inline in every rule.

### Status and scope

Proposed (roadmap R13-02, milestone R13 How we work).

**Why:** AGENTS.md on origin/dev is 46,376 bytes with 67 dates and 28 "owner's decision" clauses; rules stack exceptions (the 'Rules Oby never breaks' login paragraph has four numbered exceptions and several 'since' and 'replacing' clauses). Agents act on a superseded clause because the current one is buried.

**In:**
- new: docs/decisions/README.md (the format and an index by date).
- One file per decision named `YYYY-MM-DD-<slug>.md`, from AGENTS.md, docs/trim.md 'Decided' and the decisions that contracts cite.

**Out:**
- Changing AGENTS.md (R13-03).
- Changing any rule's meaning.
- Plans and epics: they stay in obi-ai-bot/oby-plan.

### Steps

- List every dated decision in AGENTS.md on origin/dev (`grep -o -E '20[0-9]{2}-[0-9]{2}-[0-9]{2}'`), with the paragraph it sits in.
- Group clauses that are one decision; for each, write a file with: date, quote, replaced (link), changed contracts and scenarios, status (in force or superseded by <file>).
- Mark chains: 2026-10-23 publish by hand -> superseded by 2026-10-24; Touch ID approvals -> 2026-10-24; #1563 ask -> 2026-11-10; 'Claude Code parity first' (2026-10-19) -> 2026-11-05.
- Write README.md: the format, the index, and the rule 'AGENTS.md states the rule; the decision file holds the history'.
- Ask the owner to confirm the location (this repository, beside the contracts that cite them, not oby-plan).
