## What
On `dev` an artifact can be made, opened, edited and saved, but not taken out of Oby or brought in. obid already has both halves: `GET /v1/artifacts/{id}/export/{version}?as=zip|html` (ARTIFACTS-9 and 10, `docs/api/artifacts.md`) and `POST /v1/artifacts/import` (ARTIFACTS-11), which takes a zip, a page (`text/html`) or a document (`text/markdown`) only when signed over its exact bytes (WORDS-21, `core/crates/obid/src/artifacts/export.rs`). The app has neither.

The work exists as one commit, `6344bc36`, on `origin/claude/artifacts-l4-export` (the port plan's L4). It adds:

- **Download.** An icon button in the pane's strip (lucide `Download`, labelled `Export`) opens a menu headed `Download` with `Project archive (.zip)` (with `Every file, as Claude Design keeps it: opens there unchanged` under it for a design) and `Standalone HTML`. Main reads obid's export with its own token and writes it byte for byte where its own save dialog answers (`main/artifactExport.ts`, the `artifact-export` channel; the rules in `main/previewRules.ts`: `exportArtifact`, `nameOf`, `artifactId`, `fromOne`). The file name is obid's `Content-Disposition` name, or `artifact-v<n>.<zip|html>`; a name with a `/` or a leading `.` is never used. The page sends only the id, the version and `zip` or `html`. Preview's view steps aside while the menu is open. The pane then says `Saved to <path>`, or why not.
- **Copy** in the Code tab: the file on view as the editor shows it, the owner's unsaved edit included (the app's existing `CopyButton`, labelled `Copy <path>`).
- **Import.** A `.zip`, `.html`, `.htm`, `.md` or `.markdown` file dropped on a conversation's thread (not its message box) is offered in a bar, `Import <name> as an artifact?`, with `Import` and a close button (`Don’t import it`). Nothing is sent until the owner's click on `Import`. Main signs the bytes as bytes by that label (`IMPORT` in `shared/words.ts`; `signedHeader` in `main/words.ts` hashes a `Uint8Array` as it is, never as JSON) and sends them with the type read from the bytes, never from the page (`shared/artifactImport.ts`, `importType`: `PK\x03\x04` a zip, text starting with `<` a page, else a document). Imported, the artifact opens beside the conversation. Over 257 MB, or refused by obid, the bar says why.
