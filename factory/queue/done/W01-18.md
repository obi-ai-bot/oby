## What
Three small things the reviews of W01-14 (#2855) and W01-17 (#2858) left, all in obid:

1. **The foreign mark on a redirect** (on `dev` before W01-14; factory/jobs/013-w01-14-every-job-a-flagged/build.md, Follow-ups; round-2/review-codex.md and review-security.md). When `message_as` sends the brain's words on to a follow-up because the job it was called with has ended, the relay's `foreign` mark (the words came from a conversation that read outside text) still lands only on the original job. The job that hears the words must get it, saved before delivery, as W01-14 does for `ran_unproxied`.
2. **The new follow-up's unproxied mark** (round-2/review-security.md, Notes). When `message_as` creates a new follow-up, it copies `ran_unproxied` from the newest job in the chain, not from the relay's own flag. Set it from the flag: one line where the new job is built.
3. **Agents don't know about React artifacts** (factory/jobs/016-w01-17-a-react-artifact-draws/build.md, Follow-ups). `oby_artifact`'s path description in `core/crates/obid/src/brain/tools.rs` still says "a folder with index.html". Since W01-17, obid keeps a folder with `App.tsx` or `App.jsx` and no `index.html`, or a single `.tsx`/`.jsx` file, as a Page. Say so in the description, in the same plain words, and in the agent-facing artifact docs if obid gives agents any.

## Why
1 and 2 are the same class as W01-14: words from a flagged or foreign conversation must mark the job that hears them. 3: without it, no agent ever makes a React artifact, so W01-17 is invisible.

## How
- 1: in `jobs/lanes.rs` beside W01-14's `relay`, carry the foreign mark through the redirect and save it on the recipient before delivery; nothing delivered if the save fails.
- 2: the one line where `message_as` builds the new follow-up. `jobs.rs` may only shrink: replace a line, don't add one; if that's impossible, move the construction into `jobs/lanes.rs`.
- 3: the description string in `brain/tools.rs` and any agent-facing doc that repeats it.
- `docs/contracts/lanes.md` (LANE-3a and the foreign-mark rule) names the redirect; `docs/contracts/artifacts.md` already has ARTIFACTS-26.
