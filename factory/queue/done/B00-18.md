## What
Dogfooding Oby's own factory (#2400), its inbox held 12 cards for work Oby does by itself: 8 `failed` cards (one task's follow-ups failed six times, a card each) and 3 `merge` cards ("Not merged: Follow-up: …", "Ready to merge: Follow-up: …").

## Why
The owner's default is no "Try again" or "another round" cards: Oby retries by itself, as Claude Code and T3 Code do, and asks only when the owner must decide. A card per attempt buries the cards that matter.

## How
- A failure Oby will retry by itself, a follow-up it starts by itself, and a merge result for work that merges by itself show no card; the task's own line says where it stands.
- A card appears only when the owner must decide or act, once per task, not once per attempt.
- This is a default an owner can change, not a fixed rule.

Acceptance:
- A task whose follow-ups fail three times and are retried by Oby leaves no `failed` inbox item per attempt; its task line shows the latest state.
- A merge Oby makes by itself leaves no `merge` card; one it can't make and needs the owner for leaves exactly one.
- A task that needs the owner still gets its card.
- Tests at the API boundary, named after numbered scenarios.
