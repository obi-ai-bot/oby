# fix(obid): Try again on a task that never started runs it, not a follow-up

<!-- Roadmap R02-09 · Sprint 2 · R02 Commands that are safe to repeat · effort S · risk medium -->

### Sangam's screen

engine only

### Outcome

Try again on a failed task that never started starts that same task again. Follow-ups no longer pile up.

### Status and scope

Proposed (roadmap R02-09, milestone R02 Commands that are safe to repeat).

**Why:** #1851: six follow-ups of one review. message_as refuses Try again for a job with no session ('This job never started', jobs.rs:4350), so other words and oby_continue_job start a follow-up each time.

**In:**
- A Try again from the owner on an ended job with no session: next_round with a fresh launch from its own task.
- The same for the brain's oby_continue_job.

**Out:**
- Automatic retry of prepare failures (#1943 retry-prepare).
- One card for a chain in Needs you (needs Sangam's design).

### Actors and ownership: what obid owns

- Try again on a job with no session restarts it from its task.

### Actors and ownership: what the apps show and send

- Nothing changes: Try again stays where it is.
