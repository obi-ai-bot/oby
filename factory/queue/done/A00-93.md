What. A job knows its branch, its base and the files it touched (`Job::files`), but obid serves no view of the whole change: the Electron app can only show each step's own patch inside Full session (`SessionView.tsx`, `jobPage.ts`), and the task card says "N commits on branch" with a link to GitHub. There is no way to see, in Oby, everything a task changed before or after it merges.

Why. The owner's own work now merges by itself (MERGING-44 to 48), so the moment a person would have looked at the change has gone; Oby should at least make the change easy to read. T3 Code's diff panel (`apps/web/src/components/DiffPanel.tsx` there) is what a person running agents daily expects. The window's screen for it is Sangam's to design (a question for the owner); obid's part is needed whatever the screen.

How. A loopback-only, add-only route: `GET /v1/jobs/{id}/changes` → `{base, head, files: [{path, status, additions, deletions}], diff}`, where `diff` is `git diff <merge-base>..<head>` of the job's own branch in its worktree (or in its clone after the worktree is freed, A00-69; from GitHub's compare when neither is left), capped at 1 MiB with `truncated: true` past it, and passed through obid's known-secret redaction like any other API text. `?path=` gives one file's diff. Not on the phone gateway's allowlist until the iPhone has a screen for it. A job with no branch yet answers `{files: []}`.

### Formal verification
A Kani harness over the pure function that cuts and marks a diff: the answer is never over the cap, `truncated` is true exactly when something was cut, and the cut never splits a UTF-8 character. No model: no rule decides an outcome.

Acceptance (TASKS scenarios, each a test named after it):
1. A job that committed two files answers both with their counts and a diff whose text matches `git diff` of its branch against the merge-base.
2. A diff over 1 MiB is cut at the cap and says `truncated: true`.
3. A vault secret written into a changed file is redacted in `diff`.
4. A job with no branch answers no files; an unknown job `404`; the route isn't reachable through the phone gateway.
