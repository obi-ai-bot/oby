# docs(api): split docs/runner-api.md into docs/api/<area>.md with an index

<!-- Roadmap R13-15 · Sprint 5 · R13 How we work · effort M · risk medium -->

### Sangam's screen

engine only

### Outcome

Each API area has its own file (jobs, conversations, accounts, publishing and merging, sphere, settings, events, check), named like its contract, and docs/runner-api.md becomes a short index of endpoints with links. Fewer conflicts, faster reads.

### Status and scope

Proposed (roadmap R13-15, milestone R13 How we work).

**Why:** docs/runner-api.md is 3,021 lines on origin/dev and changed in 127 of the last 200 PRs (63%); 249 fix commits touched it since 2026-10-09. 227 files cite it, and tools/brain reads it as `apiDoc` (tools/brain/brain.config.ts:13). #1653: it names routes obid no longer serves.

**In:**
- Move each section unchanged into new: docs/api/<area>.md.
- docs/runner-api.md keeps every old heading as an index line with its link, so 'docs/runner-api.md, "<section>"' citations still resolve.
- tools/brain reads docs/api/*.md.
- AGENTS.md: 'change the API doc in the same PR', per area.

**Out:**
- Rewriting the 227 citing files.
- Fixing stale routes (#1653) beyond noting them.
