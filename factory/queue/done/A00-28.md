R02-07 (#2222) lets the Electron app's main process sign a resend of the owner's words again, with no new click: the same request, within 10 seconds, at most twice (WORDS-16 in docs/contracts/signed-words.md). Its security review found the limit doesn't hold when several identical calls arrive at the same moment: apps/electron/src/main/device.ts (around lines 340-348) reads obid's /v1/status before it counts the re-sign, so concurrent calls can each pass the check and all be re-signed. obid's request-key lock still lets only one of them act, so the harm is small, but the rule as written is broken.

Fix: count the re-sign before main reads /v1/status (or otherwise make the check and the count one step), so at most two re-signs happen for one request however many calls race. Add a test named after WORDS-16 that fires several identical calls at once and fails without the fix.
