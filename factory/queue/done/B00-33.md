## What
A "Review requested" item for a pull request in another organization's repository appeared in an Oby set up for one repository (#2402): the GitHub account it uses can see several organizations.

## Why
The inbox should hold what the owner connected Oby to. Other work leaks noise into it, and shows one owner's other projects in an app they may share or demo.

## How
- Review requests, assigned issues and other GitHub inbox items come only from repositories the owner connected (their repos in Oby's config).
- An owner who wants every repository's items can say so; connected-only is the default.

Acceptance:
- A review request in a repository Oby isn't set up for makes no inbox item.
- One in a connected repository still does.
- Tests with a stand-in GitHub, no network.
