## What
R02-09 makes Try again on a task that never started rerun that same task (obid no longer refuses it with "This job never started"). The Electron app's "Give it another round" button on such a task still sends the task's own title and request as a new message (`apps/electron/src/renderer/src/live.ts`, around line 260), which starts a follow-up task instead.

## Why
Follow-ups keep piling up from the Mac app for a task that simply never ran, which is what R02-09 set out to stop.

## How
- Once R02-09 is on dev, the button on a task that never started sends Try again's words (the same call the inbox item's Try again makes), so obid reruns the task.
- For a task that did start, the button keeps today's behaviour.
- A vitest test of the renderer: on a never-started task the button sends Try again, on a started task it sends the follow-up; each fails without the change.
- Depends on R02-09.
