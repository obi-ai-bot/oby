## What
Oby's factory starts a build straight from a task file, has every pull request reviewed twice by two tools with one generic prompt, and merges on two approvals. The Claude Code factory first runs intake (accept, scope, risk, surfaces) and a spec with numbered acceptance criteria, `## Proofs` and `## Models`; routes reviewers by risk and surface (`factory/bin/route`, `factory/config.json` `routing`: code, security, proofs, ux, ui, with models per lens); and ends with an approver that checks every acceptance criterion and escalates to the owner what only the owner decides: words no Sangam screen shows, a change to a rule or a lane, security paths.

## Why
On 2026-11-15 the Claude Code factory's approver escalated A00-85 (a lane rule change) and A00-94 (new user-facing words), and caught A00-86 counting a Sphere outage as a refusal, against its own scope. Oby's factory would have merged all three. The owner wants the same quality from both.

## How
In oby-feed and the factory obid, before the build: an intake and spec job writing the same `intake.md` and `spec.md` the Claude Code factory writes (the same agent definitions in `.claude/agents/`), with the build told to meet the spec. After the build: reviews routed by `factory/bin/route`'s rules, one per lens, with the lens's model; and an approver job reading every review and the spec, which either approves or escalates. An escalated task waits for the owner with the approver's reasons, like `needs-human`. Two approvals of the exact head by different tools stay required on top.

Acceptance:
- A task's Oby job is built against a spec whose acceptance criteria the approver checks one by one.
- A pull request that adds words a person sees, or changes an AGENTS.md rule or a lane, waits for the owner and never merges on its own.
- A task routed `security` and `proofs` gets those reviewers, each a different lens, and any CHANGES sends the build a fix round with the findings.
- Tests cover routing, the approver's approve and escalate, and the fix round, with stand-ins for obid.
