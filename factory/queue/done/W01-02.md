## What
obid drives each agent tab through the window: it sends Chrome DevTools Protocol (CDP) commands to the app's main process, which relays them to the tab's `<webview>`. Main checks only the command's domain. `DOMAINS` in `apps/electron/src/main/browserRelay.ts` lets nine whole domains through (Page, Runtime, DOM, DOMSnapshot, Accessibility, Input, Network, Emulation, Log), and `run()` forwards `Page.navigate`'s URL unchecked.

obid sends 21 methods in 6 domains (list them with `git grep` over `core/crates/obid/src/browser`; `reports/w01/readers/browser-window.md` has the list found on 2026-11-21: verify it). Everything else is reach nobody uses. Through it, whoever can post to obid's relay can call:

- `Network.getAllCookies`: every sign-in kept in an agent's persistent partition;
- `DOMSnapshot.captureSnapshot`: a whole page, password fields included;
- `Page.addScriptToEvaluateOnNewDocument`: a script planted before the owner's next sign-in;
- `Runtime.addBinding`;
- `Page.navigate` to `file:///...`.

## Why
The relay is the wall between an agent and the owner's signed-in pages. A wall that lists domains has holes the size of each domain. This is a security fix: it goes early, before Fill in (which edits the same lines), and it shrinks what Fill in's own guard has to refuse.

## How
In `browserRelay.ts`, replace the domain list with a method allowlist: exactly the methods obid sends, plus main's own `Emulation.setFocusEmulationEnabled`. A command not on the list is refused with the relay's existing refusal shape and reason, and never reaches `debugger.sendCommand`. `Page.navigate` (and any other command that carries a URL to load) is refused unless the URL is a web page by the same rule `browserGuest.ts` already uses for `will-navigate` (`pageOk`): import that rule, don't copy it.

Keep the list beside a test that fails when obid starts sending a method main doesn't allow: read the method names from obid's sources in the test (as the route guard reads the apps' calls), so the two lists can't drift.

This task is the method allowlist only. The box partition's edge (`oby-box-*` partitions refusing loopback, private and link-local hosts, the live `browser-113`) is a later task: it needs obid's box partitions first.
