## What
Inbox sorting, memory and the "Since you last looked" recap use the first Claude Code account (`core/crates/obid/src/brain/calls.rs:1-5,57`; `core/crates/obid/src/triage.rs:461`). An owner with only Codex or Cursor loses them quietly: items stay unsorted for 2 minutes and then all become `needs_you`, and the recap falls back to a count.

## Why
- **Oby works with any agent** (AGENTS.md, "The social contract": vendor agnostic). A Codex-only or Cursor-only owner should get the same Oby.

## How
1. These calls pick an account by room across every connected tool, as job routing does (USAGE-11), each tool with its own prompt shape through the existing harness.
2. With no account signed in, items stay `pending` and say why; nothing is guessed.
