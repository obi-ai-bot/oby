## What
Two fixes from reports/w01/research-artifacts-oss.md, recommendation 5:

1. **A page that declares `scope` draws blank.** Sandpack's static client (`@codesandbox/sandpack-client` 2.19.8, `dist/index-599aeaf7.mjs`, `injectScriptIntoHead`, checked on `dev`) puts its console hook first in every `.html` it serves as a classic script: `<script>const scope = {...}; <consoleHook></script>`. That hook's top-level `const scope` and its minified bindings are globals of the page. An artifact script that declares `scope` (`const`, `let`, `var`, `function` or `class`) then fails with `SyntaxError: Identifier 'scope' has already been declared`, and the page draws blank. `vite.config.ts` has no patch for it. A React artifact is unaffected: its code is a module.
2. **No way to run the page again.** Board 1b has a Reload button in the pane's nav row. The pane (`renderer/src/artifacts/Pane.tsx`) has none. The static client already injects a listener for it into every page (`injectProtocolScript`: on a `{type: 'refresh'}` message, `window.location.reload()`), reached by `client.dispatch({ type: 'refresh' })`, as LibreChat's `Artifacts.tsx` `handleRefresh` does.

## Why
An agent's page that names a variable `scope` is common, and it shows nothing with no reason given. Reload is the board's control. It is also the only way to see an animation or a page's first state again without closing the pane.

## How
1. **LibreChat's plugin, copied.** Copy `sandpackConsoleIsolation` from LibreChat's `client/src/lib/sandpack.ts` (commit `4700c44`, MIT; the clone the report read) into a new `apps/electron/scripts/sandpack-isolation.mjs`, a plain script like `scripts/local-only.mjs`.
   - Keep LibreChat's MIT notice at the top: "Copyright (c) 2026 LibreChat" and the licence text from its `LICENSE`.
   - It wraps the injected hook in an IIFE: `(function () { const scope = …; <script> })();`. It changes only the static chunk (`[\\/]node_modules[\\/]@codesandbox[\\/]sandpack-client[\\/]dist[\\/]index-[^\\/]+\.(?:mjs|js)`, the file `vite.config.ts`'s `sandpackStatic()` aliases). The build fails when the injection line isn't found exactly once ("Sandpack static script injection changed; update console isolation.").
   - Add it to `vite.config.ts`'s `plugins` beside `localOnly()`. electron-vite's renderer takes that config, and vitest does too. Vite 7.3.7 and Rollup 4.64.5 take LibreChat's `transform: { filter, handler }` form as it is.
2. **Reload.**
   - `host.ts`: `window.obyReload = () => client?.dispatch({ type: 'refresh' })`.
   - `main/artifactPreview.ts`: a new `artifact-reload` channel, no arguments, answering `null`. It runs `window.obyReload?.()` in the pane's view only (never the picture's view), and only while a version is on view (`onView`). It registers through `ipc(trusted)` as `artifact-preview` does.
   - `preload/index.ts` gets `artifactReload`, and `Oby.tsx` its type beside `artifactPreview`'s.
   - `Pane.tsx`: board 1b's button (`aria-label="Reload"`, `RotateCw` size 15, strokeWidth 1.6, `icon-button is-28`). It goes in the strip before Preview and Code, where the board's nav row puts it before the address. It shows only while Preview is on view and the bridge has `artifactReload`. The browser panel's own Reload (`browser/Panel.tsx`) draws the same button.
3. **Docs.** `docs/contracts/artifacts-app.md` gets ARTIFACTSAPP-19 and 20 (the contract's highest on `dev` is ARTIFACTSAPP-18), and `artifact-reload` in its "The page into main" line. `docs/contracts/ipc.md` gets `artifact-reload`'s row.
