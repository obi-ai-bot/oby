# chore(check): a byte budget for AGENTS.md with a ratchet

<!-- Roadmap R13-04 · Sprint 4 · R13 How we work · effort S · risk low -->

### Sangam's screen

engine only

### Outcome

AGENTS.md cannot grow back silently: more bytes than the budget fail the check, and fewer bytes also fail until the budget is lowered, so each change of size is a visible edit.

### Status and scope

Proposed (roadmap R13-04, milestone R13 How we work).

**Why:** AGENTS.md changed in 15 of the last 200 PRs on dev and reached 46 KB; nothing measures it. obid_lines_limit already uses the same ratchet (fails more than 1,000 under the limit).

**In:**
- `agents_md_bytes_limit` in scripts/oby-check.sh, picked like obid_lines_limit (pick_limit), set to the size after R13-03.
- Cases in scripts/oby-check-test.sh.

**Out:**
- Budgets for per-directory AGENTS.md files.

### Actors and ownership: what obid owns

- Nothing changes in obid.

### Actors and ownership: what the apps show and send

- Nothing changes for clients.

### Files

- scripts/oby-check.sh
- scripts/oby-check-test.sh

### Steps

- Add `agents_md_bytes_limit=<wc -c AGENTS.md after R13-03>` beside obid_lines_limit, with `pick_limit`.
- Fail above it; fail when more than 512 bytes under it with the number to lower it to.
- Add the cases to scripts/oby-check-test.sh: over, far under, at the limit.
- Run scripts/oby-check-test.sh against the old script first and see the new cases fail.

### Acceptance scenarios

- None: this task changes no product behaviour.

Contract: none

### Tests

- agents_md over budget, far under budget, at budget (new cases in scripts/oby-check-test.sh)

### Done when

- scripts/oby-check-test.sh passes, and its new cases failed before the change.
- `scripts/oby-check.sh` passes on the PR's commit.
