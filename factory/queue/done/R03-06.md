# chore(web): delete apps/web and its stale docs, on the owner's yes

<!-- Roadmap R03-06 · Sprint 2 · R03 Delete what has no caller · effort S · risk low -->

### Sangam's screen

engine only

### Outcome

The owner decides whether apps/web goes. On yes, a browser client that obid stopped serving on 2026-10-27 leaves the repository, the docs stop saying obid serves it, and the gap-map issues that plan web features are closed or retargeted.

### Status and scope

Proposed (roadmap R03-06, milestone R03 Delete what has no caller).

**Why:** obid removed web.rs and /app/ in #1510; nothing serves or ships apps/web. Searched apps/electron (package.json, scripts, src: only comments say code was copied from apps/web, nothing imports it), install/package.sh (no web build), install/install.sh (copies a `web` part only if an archive has one, :393), .claude/launch.json (its web configurations are apps/electron and design/app), scripts/, tools/ and e2e/: no caller. docs/ARCHITECTURE.md:17 and :62 and docs/install.md:36, 40, 99, 133 still describe it as served. Open issues #1290, #1291, #1198, #1170, #1114 and #1228 plan web features. apps/web is 53 files, 10,942 lines with its lockfile (7,597 in src, 103 vitest cases) and has no CI.

**In:**
- Step 1: ask the owner on an issue: delete apps/web? Record the answer in docs/trim.md.
- On yes: delete apps/web; fix docs/ARCHITECTURE.md:17, 62, docs/install.md:36, 40, 99, 133 and the comment lines in core/crates/obid/src/artifacts.rs:63 and vault.rs:908 that name the web app.
- Record in docs/trim.md that a future browser client is the Electron renderer with a web runtime (shared UI, only the bridge differs).
- Close #1290, #1291, #1198, #1170 and #1114 with a link to the decision; retarget #1228 to the iPhone and Electron only.

**Out:**
- install.sh's leftover `plugins` and `web` parts (:255, :393): a follow-up chore, after checking the release archive.
- Electron comments that say a file was copied from apps/web: they can stay, git history explains them.
