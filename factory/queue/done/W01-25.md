## What

In the preview that request is refused: the preview session lets nothing off loopback go (`main/artifactPreview.ts` `lockSession`, `previewRules.ts` `allowed`), so the page draws with no styles. The app already serves Tailwind's browser build to React artifacts at `/__csb_vendor/tailwindcss-browser/index.global.js` (`main/sandpackRelay.ts`, `renderer/src/artifacts/react.ts`). A plain page just never gets it.
2. **Agents aren't told what a preview has.** Checked on `dev`: `oby_artifact`'s description in `core/crates/obid/src/brain/tools.rs` (line 166) and the job brief's artifacts line in `core/crates/obid/src/jobs.rs` (6081, `standing_rules`) say nothing of the import set. ## Why

## How
1. **The CDN tag, rewritten** (`renderer/src/artifacts/showable.ts`). This takes Open WebUI's idea: meet the code the model writes with the bundled copy (`FullHeightIframe.svelte`, `processHtmlForDeps`; its licence allows ideas only, no code). In each `.html` file of an `html` page (not a React artifact, a document or a picture), a `<script>` whose `src` is a Tailwind CDN gets `src="/__csb_vendor/tailwindcss-browser/index.global.js"`. A Tailwind CDN is:
   - `https://cdn.tailwindcss.com`, with any path, query or fragment (the Play CDN, v3);
   - `@tailwindcss/browser` on jsDelivr or unpkg, at any version.

   Before that tag goes one inline `<script>window.tailwind ??= {};</script>`, so the page's own `tailwind.config = {…}` doesn't throw. The ceiling: the vendored copy is Tailwind 4.3.5, not the Play CDN's 3. An inline `tailwind.config` and `?plugins=` don't apply, though the common utilities do. Each further library (Chart.js, Alpine) comes only with its own vendored file and licence, in its own task. Any other off-loopback request stays refused, as now. Code, Download and Export show and save the version's files as they are, with no rewrite.
   - **The guard:** `scripts/local-only.mjs` fails the build when a chunk holds `cdn.tailwindcss.com`, `cdn.jsdelivr.net` or `unpkg.com`. So the hosts are written as regular expressions with escaped dots (`cdn\.tailwindcss\.com`), which the guard doesn't match. The guard stays as it is.
2. **The import line, written once** (`brain/tools.rs`). One sentence in LibreChat's manner, in a `macro_rules!` literal (or the like) that both texts `concat!` in:
   - a React artifact is a folder with an `App.tsx` that default-exports a component rendering with no props, and no `index.html`;
   - it imports only from `react`, `react-dom` and `lucide-react` (1.55: newer icon names are missing);
   - Tailwind classes apply, nothing is fetched, so placeholder images are drawn with SVG or CSS;
   - a page's Tailwind CDN tag gets the bundled Tailwind 4, and any other CDN is refused.

   It goes at the end of `oby_artifact`'s description, beside W01-18's words. In `jobs.rs` it replaces the artifacts line at ~6081 in place, the line's own words kept before it. That is one line for one line: `jobs.rs` may only shrink (`jobs_rs_limit`). The words are for agents, not the owner, so they are this task's.
3. **Docs.** ARTIFACTSAPP-21 goes in `docs/contracts/artifacts-app.md`, and ARTIFACTS-27 in `docs/contracts/artifacts.md` (what agents are told; ARTIFACTS-26 is the highest on `dev`).
