## What
The gate is `factory/checks.sh` → `scripts/oby-check.sh` → the installed `oby-check-blok check`, which runs only the suites a change reaches (Rust, Electron, iOS, `mcp/`, then the secret scan). No suite covers `factory/`. A change only to the factory's own scripts (`factory/bin/job`, `factory/bin/gate`, `factory/bin/route`, `factory/bin/test-run`, `factory/checks.sh`) passes its gate on the secret scan alone, in about 1 second: R01-12 (#2183) did, on 2026-11-13. A00-07 (#2185) adds the first committed factory tests, `factory/tests/` (`python3 -m unittest`, stdlib only), and nothing runs them in the check.

## Why
The factory merges its own changes to how it merges, gates and cleans up. Without its tests in the gate, a broken `factory/bin/job` reaches `dev` and stalls every job after it, and nobody sees it until the next job fails.

## How
- Add a `factory` group to `scripts/oby-check.sh` and a node for it in `tools/oby-check-blok` (its workflow `workflows/oby-check.json` and the node code), named like the others, with a `maxDuration` that suits the suite (a few minutes).
- The group runs when a change touches `factory/bin/**`, `factory/checks.sh`, `factory/tests/**` or `factory/config.json`, and in a full run. It runs `python3 -m unittest discover -s factory/tests` with no network and no `gh` login: the tests use their fake `gh`.
- It takes no check lock and builds no Rust (`factory/checks.sh` already runs plans without a Rust group outside the lock, #2174).
- `OBY_CHECK_PLAN=1` prints the new group when the change reaches it.
- Proof, recorded in build.md: a branch that breaks one assertion in `factory/bin/test-run` turns the check red and names the test; the same branch without the break passes; a docs-only change doesn't run the group.
- Update `docs/runner-api.md` ("Check workflow") and `factory/README.md`. After the change, `cargo install --locked --path tools/oby-check-blok` is needed again on the Mac (AGENTS.md); say so in the PR.

Depends on A00-07's `factory/tests/` being on dev; if it isn't merged when this starts, wait for it.
