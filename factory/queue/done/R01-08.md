# feat(obid): no CLI self-update under a running job

<!-- Roadmap R01-08 · Sprint 1 · R01 Safety net · effort S · risk low -->

### Sangam's screen

uses an existing screen: apps/electron/src/renderer/src/SessionView.tsx (transcript lines as they are)

### Outcome

A CLI does not change version in the middle of a job; if it changed between rounds anyway, the job's transcript says so.

### Status and scope

Proposed (roadmap R01-08, milestone R01 Safety net).

**Why:** obid sets DISABLE_TELEMETRY and DISABLE_ERROR_REPORTING for Claude Code jobs (jobs.rs:50, CLAUDE_TELEMETRY_OFF) but not DISABLE_AUTOUPDATER; only the obi-vm image sets it (core/obi-vm/image/obi-job:7). A self-update during a run can change the stream format under the adapter.

**In:**
- DISABLE_AUTOUPDATER=1 for Claude Code runs obid starts, next to CLAUDE_TELEMETRY_OFF
- The equivalent switch for Codex and cursor-agent if each has one (else none, written in the contract)
- Between rounds: compare agentVersion with the current version (R01-07) and add one transcript line on a change

**Out:**
- The owner's own terminal CLIs, which keep updating
- Pinning or installing CLI versions

### Actors and ownership: what obid owns

- The run environment and the version compare between rounds.

### Actors and ownership: what the apps show and send

- The transcript line, shown as any obid transcript line is; no new UI.

### Files

- core/crates/obid/src/jobs.rs
- core/crates/obid/src/cli_versions.rs
- core/crates/obid/tests/agents/fake-claude
- docs/runner-api.md
- docs/contracts/cli-versions.md

### Steps

- Add DISABLE_AUTOUPDATER to the list obid sets in Jobs::launch (where CLAUDE_TELEMETRY_OFF is applied, jobs.rs ~7527); rename the const to say what it now holds.
- Find Codex's and cursor-agent's own switches in their docs; add them, or write 'none' in the contract.
- Make fake-claude print its env var so a test can assert CLIVERSIONS-5.
- Compare versions at round start using cli_versions; add the transcript line on a change.
- Document both in docs/runner-api.md.

### Acceptance scenarios

- CLIVERSIONS-5 (proposed): Given a Claude Code job, when obid starts its run, then the run's environment has DISABLE_AUTOUPDATER=1.
- CLIVERSIONS-6 (proposed): Given a job whose round 1 ran on claude 2.1.300, when round 2 starts on 2.1.310, then the transcript has one line naming both versions and agentVersion is 2.1.310.

Contract: new: docs/contracts/cli-versions.md
