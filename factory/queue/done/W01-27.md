## How
Four steps, each its own commit, in this order.

1. **recharts.** Add `recharts` (MIT) and its peer `react-is` (MIT) as devDependencies, pinned exactly.
   - `vendor-sandpack.mjs`: a `BUILT` row `['recharts', 'recharts.mjs', 'recharts', ['react', 'react-dom']]`. `entry()` writes `export * from '<module>'` for any ES package (lucide-react's case, made general).
   - `react.ts`: `VENDORED.recharts = '/__csb_vendor/recharts/recharts.mjs'`.
   - **Licences:** recharts bundles its dependencies (its d3 parts ISC through `victory-vendor`, the rest MIT). So the script writes, beside each built file, its package's `LICENSE` and a `THIRD_PARTY_LICENSES` file: each package the build took in (from the output's module ids, by each one's `package.json`), with its name, version and licence text. That holds for every row from here on. `scheduler/` stays as it is.
   - The report expects about 0.4 to 0.6 MB minified: say the real size in `build.md`.
2. **The trio.** `clsx`, `tailwind-merge` (the 3.x line, which is Tailwind 4's) and `class-variance-authority`, all MIT, as devDependencies pinned exactly. Each gets a `BUILT` row with nothing external but React, and a `VENDORED` key.
3. **shadcn's components, as LibreChat ships them.**
   - **Sources:** copy LibreChat's component sources from `packages/data-provider/src/artifacts.ts` (`artifactUIComponents`, at `4700c44`) into a new `apps/electron/resources/shadcn-src/`: `ui/<name>.tsx` per key, and `lib/utils.ts` (its `cn`).
     - Each file keeps LibreChat's MIT notice ("Copyright (c) 2026 LibreChat") and shadcn/ui's (MIT, "Copyright (c) 2023 shadcn").
     - Leave out `calendar`, `carousel` and `drawer`: they need `react-day-picker`, `embla-carousel-react` and `vaul`, each a later task with its licence.
     - That keeps 34 names: accordion, alert, alert-dialog, avatar, badge, breadcrumb, button, card, checkbox, collapsible, dialog, dropdown-menu, input, label, menubar, navigation-menu, pagination, popover, progress, radio-group, select, separator, skeleton, slider, switch, table, tabs, textarea, toast, toaster, toggle, toggle-group, tooltip and use-toast.
     - Their classes are Tailwind's plain gray palette, with no theme variables, so they draw on the vendored Tailwind 4 as they are.
     - A lucide icon a source names that 1.55 doesn't export is renamed to its 1.55 name, the change noted at the file's top.
   - **Radix:** the `@radix-ui/react-*` packages those sources import (accordion, alert-dialog, avatar, checkbox, collapsible, dialog, dropdown-menu, label, menubar, navigation-menu, popover, progress, radio-group, select, separator, slider, slot, switch, tabs, toast, toggle, toggle-group, tooltip; all MIT), as devDependencies pinned exactly.
   - **The build:** the vendor script builds `shadcn-src/` as one ES build of many entries (Vite's `lib.entry` as an object), into `resources/sandpack-vendor/shadcn/`: `ui/<name>.mjs`, `lib/utils.mjs` and shared `chunks/`. React, react-dom, `react/jsx-runtime`, lucide-react and the trio stay external, so a page has one copy of each. Radix's own shared modules sit in shared chunks, never once per component. One `DismissableLayer` stack serves a dialog and a popover together.
   - **The map:** `VENDORED` maps `/components/ui/<name>` and `/lib/utils`, as LibreChat's prompt says (not `@/components/ui`). The `@/components/ui/<name>` and `@/lib/utils` that shadcn's own docs write map to the same files (`ponytail:` one key each, nothing more). An artifact's own file of the same path still wins, as `reactShown` sets its keys after `VENDORED`.
   - **The relay:** `sandpackRelay.ts` serves every `.mjs` and `.js` under `resources/sandpack-vendor/` by `import.meta.glob(…, { query: '?raw', import: 'default', eager: true })`, in place of one import per file. Only those, and only on a preview host: `LICENSE`, `README.md` and anything else stay 404.
4. **Imports checked before running** (LlamaCoder's `findMissingPreviewModules`, `lib/preview/html.ts`; MIT, its notice by the lines taken).
   - In `reactShown`, after sucrase, its regex (`/(?:import|export)\s+(?:[^"']*?\s+from\s+)?["']([^"']+)["']/g`, plus `import("…")`) over each output. Every bare specifier is checked against the map, the artifact's own files included.
   - A missing one gets the page W01-26's marked `<pre>` (`data-oby-error`), and nothing runs. Its words, proposed for Sangam's OK: "This preview has no `<name>`.    - **The agents' line** (W01-25's sentence in `brain/tools.rs`, written once) grows to the same list, with the 34 names. W01-25's drift test then passes again.
