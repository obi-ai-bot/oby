What. A conversation keeps a list of working folders (docs/contracts/folders.md). There is no way to name such a set, reuse it, or see conversations by it.

Why. The owner works on products made of several repositories and wants each conversation to say which one it is for, as T3 Code does.

How. A project is a name and a list of folders or GitHub repositories, kept per profile. Routes, add-only: GET and POST /v1/projects, PATCH and DELETE /v1/projects/{id}. A conversation gains a project key (an id or null); with a project, its folders are the project's. Every folder passes the FOLDERS validation as today. Deleting a project leaves its conversations with no project and the folders they had. obid owns every decision; the app only shows and sends.
