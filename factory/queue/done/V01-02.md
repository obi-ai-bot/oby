## What
- **Property:** once a job's `ran_unproxied` is true, it stays true after every status and every command `transition` answers (`NextRound`, `RunEnded` of each `EndKind`), as `Change::apply` writes it and `Job::upgrade` loads it. `as_opened` keeps it when either job it reads had it.
- **Harm:** a job whose agent once ran without obid's proxy gets the owner's declared secrets at a later check, after a Try again, an end or an answer. The secrets then reach a check whose agent could reach anything.
- **Code it covers:**
  - `core/crates/obid/src/job/lifecycle.rs`: `transition`, `ended`, `Change::apply`, `as_opened`.
  - `core/crates/obid/src/job.rs`: the field `Job::ran_unproxied` ("Never unset") and `Job::upgrade`, which jobs.rs runs on each job it loads. Read only.
  - Neither lifecycle function writes the field today, so the property is expected to hold.
- **Read, not proved (async `Jobs` methods Kani can't build), and listed in the skill with the tests that cover them:**
  - The refusal: `Jobs::ran_unproxied` (jobs/lanes.rs) feeds `raw_network` in `Jobs::checking_with_turn` (jobs/check_run.rs: `spec.network && (!sandbox.confines_egress() || self.ran_unproxied(id))`), and from there `Jobs::code_refuses_secrets` (jobs/secrets.rs). The `spec.network &&` term holds because every agent spec sets `network: true` today (jobs/turns.rs, jobs/lanes.rs, jobs/logins.rs). The skill records that as an assumption.
  - The other writers: `Jobs::launched` (`j.ran_unproxied || own`), `Jobs::kept_unproxied` (`= true`), `Jobs::create` (jobs.rs: a follow-up takes `new.ran_unproxied || of.ran_unproxied`), and `brain::written_in`. None sets it false.
  - Their tests: `lane_3a_a_mark_that_cant_be_kept_is_an_error`, `lane_3a_a_new_follow_up_takes_the_relays_unproxied_flag` and the other `lane_3a_*` (jobs/lanes.rs, brain/open_artifact.rs, tests/github_work.rs, tests/conversation_harness.rs), and `lanes_6_an_own_jobs_check_has_no_network`.

## Why
Tests show one Try again keeps the mark. A proof shows that no command, in any status, clears it. `docs/contracts/lanes.md` promises "from its first own launch on" and "never undone", and nothing exhaustive covers that today (reports/v01/verification-plan.md, rank 3).
