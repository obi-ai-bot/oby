Design: docs/design/oby-home/ (README.md and the numbered screenshots; the owner approved these screens on 2026-11-15, and Sangam's components and words lead where they differ). Screens 08 to 10. The app calls them Agents; obid's API already uses "agent" for the tool (claude, codex, cursor), so the API needs another word. "helper" is used here; the owner or Sangam may pick another before it ships.

What. Oby only does development work in repositories. There is nothing for general work kept by a named assistant, as OpenBot has.

How. A helper is a name, a colour, what it helps with (its standing instructions), the tool it runs on, and the connectors it may use; it belongs to one profile and has one ongoing conversation. Routes, add-only: GET and POST /v1/helpers, PATCH and DELETE /v1/helpers/{id}. Words sent to a helper's conversation run a turn on its tool with its instructions. A run uses only the connectors the helper was given. A helper may have a routine (the routines that exist), and its conversation says when one ran. No vault secret ever reaches the tool (the non-negotiable): connectors are reached by obid, as today.
