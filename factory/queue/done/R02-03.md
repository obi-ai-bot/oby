# feat(obid): a receipt store for requests that create work

<!-- Roadmap R02-03 · Sprint 1 · R02 Commands that are safe to repeat · effort S · risk low -->

### Sangam's screen

engine only

### Outcome

One place in obid remembers, for 24 hours and across restarts, which request key made which answer. Every endpoint family after it uses this store instead of its own rule.

### Status and scope

Proposed (roadmap R02-03, milestone R02 Commands that are safe to repeat).

**Why:** No route that creates a job has a request key today. POST /v1/plans has one (the turn `id`, brain/mod.rs:235 `begun.repeated`), but it lives in Conversations, not in a store other routes can use. #1851: six follow-ups for one review.

**In:**
- new module receipts.rs: put(key, route, body hash, status, answer, job id), get(key), sweep after 24 hours.
- Files in home/receipts/, one per key, written with store::write_private.

**Out:**
- Wiring any route (R02-04, R02-05, R02-06).
- Changing how POST /v1/plans dedupes its turn id.

### Actors and ownership: what obid owns

- Receipts: key (1 to 128 characters), route, body hash, status, answer, job id, created.

### Actors and ownership: what the apps show and send

- Nothing changes for clients.

### Files

- new: core/crates/obid/src/receipts.rs
- core/crates/obid/src/lib.rs
- core/crates/obid/src/store.rs
- new: docs/contracts/receipts.md

### Steps

- Write docs/contracts/receipts.md with RECEIPTS-1 to 4 marked proposed.
- Add receipts.rs with a lock per key so two requests with one key wait for each other.
- Hash the body with sha256 after a canonical JSON encode; store the hash, not the body (no secret on disk).
- Sweep at start and once an hour.
- Write the four tests in receipts.rs.

### Acceptance scenarios

- RECEIPTS-1 (proposed): Given a receipt for key K, when the same route asks with K and the same body within 24 hours, then the store returns the first status and answer.
- RECEIPTS-2 (proposed): Given a receipt for key K, when a request with K has a different body, then the store says conflict.
- RECEIPTS-3 (proposed): Given a receipt written before obid restarted, when obid starts, then the receipt is still found.
- RECEIPTS-4 (proposed): Given a receipt older than 24 hours, when obid sweeps, then the file is gone and K is free.

Contract: new: docs/contracts/receipts.md (prefix RECEIPTS)
