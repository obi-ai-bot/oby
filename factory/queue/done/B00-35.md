## What
Task A00-96's follow-up failed six times in a row in Oby's factory, each a new attempt and a new card, with no stop and no single explanation (#2404). Why each attempt failed hasn't been read yet.

## Why
Retrying the same failure wastes the owner's usage and time, and hides the reason. The owner wants Oby to retry by itself, but not endlessly.

## How
- First, read why A00-96's follow-ups failed, from those jobs, and write it down.
- Then: when a task's follow-ups fail the same way a set number of times, Oby stops starting more, keeps the task waiting, and says once, in plain words, why and what would unblock it.
- The number is a default an owner can change.

Acceptance:
- Three follow-ups failing for the same reason lead to no fourth; the task says why once.
- A follow-up that fails for a new reason is still tried.
- The owner's word starts it again.
- Tests at the API boundary.
