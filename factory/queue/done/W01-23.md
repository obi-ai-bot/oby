## What
Two leftovers of W01-17 (#2858), React artifacts:

1. **The card picture can be blank on a slow Mac** (factory/jobs/016-w01-17-a-react-artifact-draws/build.md, Follow-ups). W01-15's "drawn" signal (`window.obyDrawn` in `renderer/src/artifacts/host.ts`) fires on the frame's first `load` after Sandpack's `done`. A React artifact renders after that load, so `main/artifactPreview.ts` can take the picture before React has drawn.
2. **The error text's first letter is cut off** (round-1/review-ui.md, Notes). The compile/import error `<pre>` that `renderer/src/artifacts/react.ts` writes (~lines 21 and 28) has no inset, so it sits flush against the frame's edge and the card's picture crops "Failed" to "ailed".

## How
1. For a React artifact only, the host page's drawn signal resolves after React's first commit: the generated `index.html` (`react.ts`) posts a "rendered" message from the frame once `createRoot(...).render` has run and one `requestAnimationFrame` has passed, and `host.ts` resolves `obyDrawn` on that message (or on the error `<pre>` being written). The 4 s ceiling in `artifactPreview.ts` stays. Other kinds keep W01-15's signal.
2. The error `<pre>`: `padding: 16px; margin: 0;` and the wrap W01-17 added. Style only; the artifact's own `<pre>`s are untouched.
